## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Pest 3 (PHPUnit 11 engine) |
| **Config file** | `phpunit.xml` (repo root) |

| **Full suite command** | `vendor/bin/pest` |
| **Estimated runtime** | ~45 s full suite (project current at ~30 s; 16.1.1 adds ≈ 15 s of new feature tests) |

---

## Sampling Rate

- **After every task commit:** Run `vendor/bin/pest --filter='{TestClass}'` for that task's bound Pest class
- **After every plan wave:** Run `vendor/bin/pest --group=phase-16.1.1` (planner tags new tests with `#[Group('phase-16.1.1')]`)
- **Before `/gsd:verify-work`:** Full suite (`vendor/bin/pest`) + `vendor/bin/phpstan analyse --memory-limit=2G` + `vendor/bin/pint --test` must all be green
- **Max feedback latency:** 60 seconds
