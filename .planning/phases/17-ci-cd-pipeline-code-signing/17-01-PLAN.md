<objective>
Set the versioning baseline for the entire v0.x → v1.0.0 closeout series.

Purpose: D-01..D-04 + D-16..D-18 lock the versioning policy. Without this baseline, every subsequent release plan (17-04, 17-05, 17-19, 17-20) has no contract for what version string appears in `/health`, in `latest.yml`, in the bundle name, or in the GitHub Release title. This plan flips the `config/nativephp.php` default from the legacy `'1.0.0'` to `'0.0.0-dev'` (so a non-CI build is obviously a dev build), documents the v0.x → v1.0.0 policy in `.docs/cicd/release-cadence.md`, and deletes every existing local tag (none ever pointed to ship-quality builds and they would corrupt electron-updater channel ordering once the auto-update pipeline goes live).

Output: One config flip + one docs file + a clean tag namespace.
</objective>
