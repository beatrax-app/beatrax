<!-- EnsureAppKey contract -->
Class: Modules\Core\Internal\Bootstrap\EnsureAppKey
Constructor DI: UserDataPathService $paths, ConfigRepository $config, ConsoleKernel $artisan (or thin Artisan wrapper)
public function run(): void

The existing FirstLaunchBootstrap (Phase 15-05) runs idempotent bootstraps on every launch — runPendingMigrations() etc. EnsureAppKey::run() is added as one more chained idempotent step AFTER runPendingMigrations(), BEFORE OAuth-secrets-key generation (so APP_KEY exists when the secrets table encrypts).
