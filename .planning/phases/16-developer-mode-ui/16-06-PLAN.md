- `final readonly class QueueActions`. Constructor DI on `Illuminate\Queue\Failed\FailedJobProviderInterface $failed`, `Illuminate\Bus\BatchRepository $batches`, `Illuminate\Database\DatabaseManager $db`, `AuditWriter $audit`, `CurrentUser $currentUser`.

    * `retryFailed(string $uuid): void` — looks up the failed job, re-dispatches via `Queue::push()` reading the payload, then `$this->failed->forget($uuid);` + audit row (`queue.failed.retry`). RESEARCH § Pattern 6 has the exact code.

    * `cancelBatch(string $batchId): void` — `$batch = Bus::findBatch($batchId); $batch?->cancel();` + audit row (`queue.batch.cancel`).
    * `deleteBatch(string $batchId): void` — `$this->batches->delete($batchId);` + audit row.
    * `retryBatchFailures(string $batchId): void` — `$batch?->retryFailures();` (verify the exact method name) + audit row.
    * `bulkRetry(array $uuids): void` — loop retryFailed; single-confirm gate at the Livewire level, not here.
    * `bulkDelete(array $ids, string $kind): void` — loop deletePending or forgetFailed depending on `$kind`; triple-gate at the Livewire level dispatches `triple-gate:open` first.
