- Single-invokable controller. Method-DI on `RedactSecretsProcessor`, `UserDataPathService` (resolves `storage/logs/` path).

- Open file with `fopen($path, 'r')`; `fseek($f, 0, SEEK_END)`; remember `clearstatcache(); $size = filesize($path); $inode = stat($path)['ino'];`.
- Loop:
  - `usleep(250_000);` (250ms cadence per D-28)
  - `clearstatcache(); $newSize = filesize($path); $newInode = stat($path)['ino'];`
  - If `$newInode !== $inode || $newSize < $size` (rotation): `fclose($f); $f = fopen($path, 'r');` (or open the new day's file if path computed by date and the rollover happened). Reset offset to 0; update $size + $inode.
  - Read new bytes via `fseek($f, $size)`. `$chunk = fread($f, 65536)` (or up to EOF). Update $size.
  - For each complete line in $chunk: apply `RedactSecretsProcessor::scrub($line)` (the on-stream re-application per D-29) → emit as `data: ` event with severity + channel + timestamp parsed out from the standard Laravel log line format.
  - `if (connection_aborted()) break;`

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Application log writes → disk | All Laravel logger calls (`logger()->info()`, `Log::error()`, etc.) pass through Monolog handlers; the `tap` array binds PushRedactProcessor to every handler so the processor runs BEFORE the formatter writes the record. Secrets never hit disk. |
| Log file → SSE stream | The on-stream redaction in LogStreamController is defense-in-depth. Even if a log line slipped on-write redaction (e.g. a 3rd-party tool wrote directly to the file), the stream re-applies the same processor. |
| OAuth secret rotation → scrub-set | Eloquent observer busts the cache on save/delete; the next log line picks up the new compiled regex. No stale-secret window. |
| /dev/logs/context endpoint | Accepts `offset` + `radius` params; both are integer-validated (Laravel form-request validation); path is fixed (UserDataPathService); no LFI possible. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-03 | Information Disclosure | OAuth tokens / Bearer headers / JWTs leak through log file or live stream | mitigate | Belt + braces (D-29). RedactSecretsProcessor runs at on-write (via tap on every channel) AND on-stream (via direct invocation in LogStreamController). Pest tests cover both layers explicitly (Test 4 unit + Test 4 feature). |
| T-16-17 | Information Disclosure | Stale OAuth secret in scrub-set after rotation | mitigate | OAuthScrubSet busts on `OAuthSecret` save/delete via Eloquent observer (D-30). Tested in OAuthScrubSetBustTest Test 5. |
| T-16-18 | Information Disclosure | Log tailer reads outside `storage/logs/` (path traversal) | mitigate | Path is pinned in LogStreamController via UserDataPathService → `storage_path('logs/laravel-' . date('Y-m-d') . '.log')`. No user input flows into the path computation. |
| T-16-19 | Information Disclosure | Context endpoint returns ±N lines around a forged offset (reads beyond the file) | mitigate | The endpoint clamps `offset` to `[0, lineCount-1]` and `radius` to `[0, 50]` via Laravel validation; SplFileObject naturally handles EOF. No LFI. |
| T-16-20 | DoS | SSE stream long-lived connection consumes a PHP worker indefinitely | accept | This is the inherent cost of SSE. Laravel's default request timeout is high; the controller's `connection_aborted()` check kills the loop when the browser closes the EventSource. NativePHP bundle runs a sufficient worker pool. | T-16-21 | Performance | Redaction processor adds CPU per log line | mitigate | Pre-compiled regex (per Pitfall 8) — single `preg_replace` per line, not `foreach str_replace`. OAuthScrubSet caches the compiled pattern across requests; observer bust forces re-compile only on secret rotation. |
