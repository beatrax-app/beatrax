## Spacing Scale

Declared values (all multiples of 4, sourced from sketch `--space-*` tokens):

| Token | Value | Usage |
|-------|-------|-------|
| 1 | 4px | Icon gaps, kbd internal padding, status-pill dot gap |
| 2 | 8px | Compact element spacing, sidebar item vertical padding, table cell padding (dev console) |
| 3 | 12px | Run-card gap stack, sidebar item horizontal padding, palette result gap |
| 4 | 16px | Default element spacing, card padding (dev console), sidebar padding |
| 5 | 20px | Console-pane horizontal padding |
| 6 | 24px | Section padding, card padding (main app) |
| 8 | 32px | Layout gaps |
| 10 | 40px | Larger layout gaps |
| 12 | 48px | Main-app section gaps (`space-y-12` rhythm survives outside `/dev/*`) |

**Density rules (locked, per `component-library.md`):**

- **Main app surfaces** — section gaps 48px (`space-y-12`), card padding 24px.
- **Dev Console surfaces (`/dev/*`)** — section gaps 16–24px, card padding 12–16px, sidebar item vertical padding 8px, dev-console table cells `9px 10px`.
- **Console pane head** — 18px vertical / 20px horizontal padding.
- **Triple-gate modal width** — 460px fixed.
- **Palette width** — 760px at viewports ≥1100px; collapses to 640px below (Flux modal breakpoint handles this).
- **Sidebar width** — 248px in main app; 220px inside `/dev/*`.

Exceptions:

- `padding: 1px 5px` on `.kbd` chips — kbd is a hint element, not a touch target; the 10-11px font size requires sub-4px padding to render correctly. Validated in sketch 001.
- `padding: 2px 8px` on `.status-pill` — pill geometry requires sub-4px vertical padding to keep the 6px dot vertically centered.
- `padding: 2px 6px` / `padding: 2px 7px` on tier chips and palette source chips — same uppercase-10.5px-glyph constraint.

These three exceptions are pill/chip/kbd-only and never propagate to layout containers, cards, or sidebar items.

## Typography

Sourced from sketch `--text-*` tokens. Two weights only (regular 400 + semibold 600); the dev console's emphasis comes from monospace + color + tabular numerics, never from extra weight grades.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body (dev console) | 13px (`--text-sm` = 0.8125rem) | 400 | 1.5 | Default body in every `/dev/*` page, sidebar item label, table cell |
| Body (main app) | 15px (`--text-base` = 0.9375rem) | 400 | 1.5 | Default body outside `/dev/*` |
| Dev page title | 22px (`--text-xl` = 1.375rem) | 600 | 1.2 | `/dev/*` page headers ("Artisan runner", "Queue inspector") |
| KPI value | 32px (`--text-3xl` = 2rem) | 600 | 1.2 | Console-pane headline metrics (heartbeat seconds, queue counts) |

**Supporting roles (still within the two-weight constraint):**

- **Footnotes / kbd hints** — 10–12px regular (`.kbd`, sparkline labels). Always sized 10–11px to read as hints, never as primary affordances.
- **Section labels** — 10.5px regular, uppercase, `letter-spacing: 0.06em`, color `--color-text-faint`. Used for sidebar section headings ("THIS MONTH", "MONEY"), table column headers, day-group labels in the artisan timeline ("Today, 24 May").
- **Mono runs** — `JetBrains Mono` 12–13px regular for commands, run_ids, pids, payloads, SQL input, log lines. The `.cmd` class inside run-card headers may use 500 weight (still within "two weight grades" because Inter regular + JetBrains Mono semi is the only secondary appearance — sketch validated this as readable).

**Numerics:**

- `font-variant-numeric: tabular-nums` applied to **every** counter, KPI, badge, amount, exit code, duration, row count, sparkline label.
- `font-feature-settings: 'tnum'` already set on `<html>` in the existing `app.blade.php` — extend if necessary.

**Heading hierarchy in `/dev/*`:**

1. Page title — 22px / 600
2. Card header — 13–15px / 600
3. Section label — 10.5px / 600 uppercase

No `h4`–`h6` analogues. Information density comes from cards + tables, not heading depth.

## Color

Calm slate Linear/Notion aesthetic. Locked palette from `Skill("sketch-findings-diederik")/sources/themes/default.css`. The 60/30/10 split holds; accent is **reserved for state, not decoration** — the entire design hangs on this rule.

| Role | Value (light / dark) | Usage |
|------|----------------------|-------|
| Dominant (60%) — page bg | `#ffffff` / `#020617` (slate-950) | Page background, html root |
| Dominant subtle | `#f8fafc` (slate-50) / `#0b1220` | Sidebar bg, card-header bg, table thead, palette rail |
| Secondary (30%) — surface | `#ffffff` / `#0b1220` | Card body, KPI tile |
| Secondary raised | `#ffffff` / `#0f172a` (slate-900) | Modal, palette modal |
| Secondary hover | `#f1f5f9` (slate-100) / `#1e293b` (slate-800) | Hover row, active nav, chip bg |
| Border | `#e2e8f0` (slate-200) / `#1e293b` | Default 1px border on every card / row / divider |
| Border strong | `#cbd5e1` (slate-300) / `#334155` (slate-700) | Hover border, dashed Dev block border |
| Text | `#0f172a` (slate-900) / `#f1f5f9` (slate-100) | Body |
| Text muted | `#64748b` (slate-500) / `#94a3b8` (slate-400) | Secondary text, section labels, table muted |
| Text faint | `#94a3b8` (slate-400) / `#64748b` | Tertiary, placeholders, kbd |
| Accent — OK (10%) | `#059669` / `#10b981` (emerald) | Status pill `ok`, worker heartbeat `<30s`, safe tier chip, switch `on`, dev-block live dot |
| Accent — Info (10%) | `#2563eb` / `#60a5fa` (blue) | Run-card `running` border + 3px glow, palette action source chip, inline action links ("Open queue inspector →") |
| Destructive | `#be123c` / `#f43f5e` (rose) | Run-card `failed` border, destructive tier chip, fail status pill, triple-gate modal header, queue failed alert badge, danger button |
| Warning | `#b45309` / `#f59e0b` (amber) | Warn status pill, Dev Console `ON` chip, palette `dev · safe` source chip, worker heartbeat 30–60s |

**Accent reserved for (explicit list — accent NEVER decorates a generic element):**

1. **Run-card border + 3px glow** when status is `running` (blue) or `failed` (rose).
2. **Status pill** dot + bg + text (ok/warn/fail/muted variants only).
3. **Tier chip** on dev-mode-audit rows, run cards, palette dev rows (`safe` = emerald, `destructive` = rose).
4. **Palette source chip** (`view` = muted, `dev · safe` = amber, `action` = blue).
5. **Sidebar badge `alert` variant** (queue failed count, drift alerts) — rose.
6. **Sidebar Dev-block live dot + emerald glow** — emerald, animated.
7. **Console-pane metrics** — value-positive / value-warn / value-error classes color the headline numbers only.
8. **Triple-gate modal header bg** — rose-tinted (`--color-rose-bg`) to mark the destructive surface.
9. **Inline action links inside open-alerts list** (e.g. "Re-auth →") — blue.
10. **Doctor probe pass/warn/fail row glyph** — emerald check / amber warn / rose X.

**Never accent:** section dividers, card headers without state, sidebar items at rest, table headers, run-card "Done" state (uses the muted dot — green is reserved for run-card-out colour, not the border).

**Primary button color:** inverted slate fill (`--color-text` on `--color-text-inverse`) — NOT blue. The "calm Linear/Notion aesthetic relies on this inversion" per `component-library.md`. Don't introduce a blue primary.

**Three theme-locked exceptions** (do NOT flip with `.dark` class):

1. **Console pane** on `/dev` overview — fixed `#0b1220` bg / `#f1f5f9` text / `#1e293b` dividers regardless of theme. Inline on the pane; tokens do not enter `default.css`.
2. **Run-card `.run-card-out`** output area — fixed `#0b1220` bg / `#e2e8f0` text.
3. **Triple-gate modal mono `.gate-cmd`** preview row — slate-50 bg even in light, picks up the surrounding pane treatment.

These are deliberate dark insets that read as "you are looking at a console" surfaces.

- Always render command names in monospace, even inline in body copy.

## Accessibility & Interaction

- **404 not 403** on every `/dev/*` route for non-developers — server-side absent, not CSS-hidden. The Dev block in the sidebar is also server-side absent from the DOM for non-developers (per `app-shell-and-navigation.md`).
- **Keyboard model** is first-class: ⌘K opens palette, ⌘. opens `/dev`, ↑/↓/Tab/↩/Esc all bound inside the palette. The triple-gate modal traps focus; Esc and Cancel exit; click-outside does NOT exit.
- **No `alert()` / `confirm()`** browser primitives — they don't theme, can't preview the resolved command, can't enforce the typed-name gate.
- **Form labels** on every arg-schema input (Flux pattern provides this) — placeholder is not a substitute for label.
- **Focus rings** inherit the Flux default; the Dev block dashed border and run-card state borders are visual-only and never replace focus indication.
