## Phase Goal

**As a** developer logged into the diederik desktop app, **I want to** browse to `/dev` and see a placeholder Dev Console overview page rendered through the dev-shell sidebar, AND see a working Developer toggle on my Settings page, AND know that any partner-account user hitting `/dev/anything` receives a 404 instead of any leakage that the Dev Console exists, **so that** the rest of Phase 16's panels (artisan runner, log tailer, queue inspector, doctor, SQL, palette) can be authored against an already-bound module skeleton without reinventing the gate, the layout, the package dependencies, or the contract surface.

## CONTEXT DECISION RECONCILIATION (D-23 / spatie version)

CONTEXT D-23 prescribes `spatie/laravel-activitylog ^4.12`. RESEARCH Pitfall 3 proves `^4.12` cannot resolve under this project's Laravel 13 + PHP 8.5 — v4 requires Laravel 9/10/11 only. The correct constraint is **`^5.0`** (v5.0.0 released 2026-03-25, supports Laravel 12/13 + PHP 8.4+; the `activity()->log()` call-site API and the `config('activitylog.table_name')` override are unchanged between v4 and v5).

**Decision (this plan):** Use `^5.0`. The PHP-8.4 minimum is comfortably met (project dev runs 8.5, shipped bundle runs 8.4 per Phase 15-05 D). This supersedes CONTEXT D-23's version pin; documented here so the executor does not waste a cycle attempting `^4.12` and discovering it cannot resolve.

## CONTEXT DECISION RECONCILIATION (D-45 / SQL validator)

CONTEXT D-45 prescribes the `Doctrine\SqlFormatter\Tokenizer` for the SELECT-only guard. RESEARCH Pitfall 2 confirms that class is marked `@internal` in upstream. RESEARCH Q2 mitigation: wrap the tokenizer behind a single `SelectOnlyValidator` class (16-07's responsibility) + a Pest contract test that locks the rejection cases. The plan honors CONTEXT D-45 with this mitigation in 16-07. THIS plan only installs `doctrine/sql-formatter ^1.5` and records the constraint; the wrapper class lives in 16-07.

## STREAM TRANSPORT LOCK (D-16 / D-28)

The orchestrator flagged that CONTEXT D-16 and D-28 lock the SSE-controller path (not Livewire 4 `wire:stream`). RESEARCH Pitfall 1 confirms `wire:stream` is incompatible with Octane and lacks page-refresh reconnect. THIS plan establishes the SSE infrastructure expectation but the controllers themselves land in 16-04 (artisan stream) + 16-05 (log stream). No Wave 0 work in this plan needs to touch the transport choice; the decision is recorded here so downstream plans inherit it without revisiting.
