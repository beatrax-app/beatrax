SelectOnlyValidator implementation (per RESEARCH Q2 + Pattern 5):
- `final class SelectOnlyValidator`. Constructor injects nothing (Tokenizer is instantiated inline — it's `new Tokenizer()` per its public surface).
- `validate(string $sql): void`:
  1. Reject `preg_match('/;\\s*\\S/', $sql) === 1` → throw ValidationException with `sql=semicolon_followed_by_statement`.
  2. `$tokens = (new Tokenizer())->tokenize($sql);` — wrap in try/catch in case future doctrine/sql-formatter throws differently.
  3. Iterate tokens; skip whitespace + comment + block comment tokens; first non-skip token must be `SELECT` (case-insensitive); else throw with `sql=first_token_not_select:{token}`.
  4. If iteration ends without finding any non-skip token, throw `sql=empty_statement`.
- The `@internal` annotation on Tokenizer is documented in the class PHPDoc + the contract test ("This file is the single seam for doctrine/sql-formatter; if you change it, the contract test in tests/Contracts/SelectOnlyValidatorContractTest.php will fail.").

ReadOnlySqliteConnection:
- `final readonly class ReadOnlySqliteConnection`. Constructor DI on `Illuminate\Database\DatabaseManager`.
- `execute(string $sql): array{rows: list<array<string,mixed>>, duration_ms: int}`:
  - `$conn = $this->db->connection('readonly_select');` — the connection registered in 16-03's config/database.php edit.
  - `$pdo = $conn->getPdo(); $pdo->exec('PRAGMA query_only = 1');` — set per connection (PRAGMAs are connection-scoped in SQLite).
  - `set_time_limit(5);` — wall-clock cap (RESEARCH Pitfall 7).
  - `$start = hrtime(true); $rows = $conn->select($sql); $duration = (int) ((hrtime(true) - $start) / 1_000_000);`.
  - Returns `['rows' => $rows, 'duration_ms' => $duration]`.
