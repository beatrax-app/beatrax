## Decisions Made

See `key-decisions` in the frontmatter. The three most consequential at runtime:

1. **predis/predis over PECL phpredis.** Matches the project's anti-PECL posture from Phase 1 (webklex/php-imap chosen over ddeboer/imap for the same reason). Avoids a build-step requirement on contributors' machines.
2. **Container-resolved Gate inside `HorizonServiceProvider::gate()`.** The parent class's documented override hook expects facade-style `Gate::define()` calls; the project's larastan-strict `noFacadeRule` rejects that. The workaround — `$gate = $this->app->make(Gate::class); $gate->define(...)` — produces the same registration without tripping the strict-rule. Pattern is documented in `patterns-established` so future provider overrides (`viewTelescope`, etc.) can follow the same shape.
3. **Single-supervisor / single-process in the local Horizon environment.** The published default is 3 processes for `local`; this project only needs one because the per-user `ShouldBeUniqueUntilProcessing` lock that the chain-resolver job uses serialises everything that matters anyway, and a single human can't issue concurrent imports.
