<objective>
Land the v3 fingerprint foundation that every subsequent plan in Phase 2 depends on:

1. Bump `FingerprintComposer::NORMALIZATION_VERSION` from 2 → 3, drop `source_ref` from the tuple, widen with `booked_at` (D-21 + D-22).
2. Ship `diederik:rederive-fingerprints` artisan command with collision pre-check + dry-run + confirm flags (D-21a).
3. Migration ordering per D-21a + RESEARCH.md "Migration ordering" §:
   - re-derive v2 → v3 in-place (invokes the artisan command, aborts on collision),
   - add `transactions.enriched_from` nullable JSON column (D-28a),
   - add `import_runs.enriched_count` unsigned integer column (default 0),
   - replace the composite UNIQUE index on `transactions` so its tuple matches the v3 fingerprint (drops `source_ref` from the index, adds `booked_at`). The SHA-256 `(user_id, fingerprint)` UNIQUE is preserved.
4. Ship the `FingerprintDisposition` discriminated DTO + three variants + `PendingEnrichment` DTO so Wave 2 adapters and Wave 3 enrichment pipeline can construct them without depending on each other's implementation files.

No adapters, no wizard, no Blade, no enrichment logic in this plan — those land in Plans 02-03 / 02-04 / 02-05. This plan is the pure foundation that everything else builds on.

Purpose: D-21 changes the meaning of "same transaction" — every Wave 2+ adapter MUST already be hashing under v3 so cross-format dedup tests in Plan 02-05 work without a second migration. Doing v3 in Wave 1 also lets Plans 02-03 and 02-04 run in parallel: both adapters consume `FingerprintComposer::compose()` via the existing `NormalizeStage`, and the column adds + DTOs unblock the Plan 02-05 enrichment writer.

Output: a re-derived `transactions` table on v3, a new JSON column on `transactions`, a new integer column on `import_runs`, an updated composite UNIQUE index that matches the v3 tuple, and five new DTO files in `Modules/Import/Public/Dto/`.

```php
final class FingerprintComposer
{
    public const NORMALIZATION_VERSION = 3;

    public function compose(CanonicalTransaction $tx): string
    {
        $tuple = implode('|', [
            (string) ($tx->userId ?? 0),
            (string) $tx->accountId,
            $tx->postedAt->toDateString(),
            $tx->bookedAt->toDateTimeString(),  // NEW in v3
            (string) $tx->amountMinor,
            $tx->currency,
            $tx->counterpartyNormalized,
            // source_ref REMOVED in v3
        ]);

        return hash('sha256', $tuple);
    }

    public function normalize(string $rawName): string { /* unchanged */ }
    public function version(): int { return self::NORMALIZATION_VERSION; }
}
```
