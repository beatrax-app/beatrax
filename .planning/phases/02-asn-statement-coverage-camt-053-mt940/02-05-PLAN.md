Rank function (the "strength" ordering for source_ref enrichment — implemented in FingerprintStage):
```php
private function refRank(?string $ref, string $format): int
{
    if ($ref === null || $ref === '') return 0;
    return match ($format) {
        'asn-camt053' => 4,  // EndToEndId — the strongest
        'asn-mt940'   => 2,  // :61: customer_reference or :86: EREF
        'asn-csv'     => 1,  // raw CSV sequence number
        default       => 0,
    };
}
```

"Stronger" decision rule (D-28):
- incoming_rank > existing_rank → ENRICH
- incoming_rank <= existing_rank → DUPLICATE
- incoming non-null + existing null → ENRICH (rank 4 > 0, etc.)
- incoming null → never enrich (rank 0)

`ApplyEnrichments` action body sketch:
```php
public function __invoke(array $enrichments, User $user): int
{
    if ($enrichments === []) return 0;
    $count = 0;
    foreach ($enrichments as $e) {
        $applied = $this->db->connection()->transaction(function () use ($e, $user) {
            $row = $this->db->connection()
                ->table('transactions')
                ->where('id', $e->existingTransactionId)
                ->where('user_id', $user->id)
                ->lockForUpdate()
                ->first(['id', 'source_ref', 'enriched_from']);
            if ($row === null) return false;
            // Defence-in-depth: only enrich if the incoming ref is still strictly stronger than the current
            if ($row->source_ref !== null && $row->source_ref !== '' && $row->source_ref === $e->newSourceRef) {
                return false;  // already enriched (race-condition skip)
            }
            $provenance = $this->decodeEnrichedFrom($row->enriched_from);
            $provenance[] = [
                'format' => $e->sourceFormat,
                'ran_at' => $this->clock->now()->toIso8601String(),
                'import_run_id' => $e->importRunId,
                'added' => ['source_ref'],
            ];
            $this->db->connection()->table('transactions')
                ->where('id', $e->existingTransactionId)
                ->update([
                    'source_ref' => $e->newSourceRef,
                    'enriched_from' => json_encode($provenance, JSON_THROW_ON_ERROR),
                    'updated_at' => $this->clock->now(),
                ]);
            return true;
        });
        if ($applied) $count++;
    }
    return $count;
}
```

    ```php
    public function classify(CanonicalTransaction $tx, User $user): FingerprintDisposition
    {
        $fingerprint = $this->fingerprints->compose($tx);
        $existing = $this->db->connection()
            ->table('transactions')
            ->where('user_id', $user->id)
            ->where('fingerprint', $fingerprint)

        $incomingRank = $this->refRank($tx->sourceRef, $tx->sourceFormat);

        if ($incomingRank > $existingRank) {
            return FingerprintDisposition::enriched(
                existingId: (int) $existing->id,
                fromSourceRef: $existing->source_ref,
                toSourceRef: (string) $tx->sourceRef,
            );
        }

        return FingerprintDisposition::duplicate();
    }

    private function refRank(?string $ref, string $format): int
    {
        if ($ref === null || $ref === '') return 0;
        return match ($format) {
            'asn-camt053' => 4,
            'asn-mt940'   => 2,
            'asn-csv'     => 1,
            default       => 0,
        };
    }

    /** @deprecated Use classify(). Retained for one-version transition. */
    public function isExistingFingerprint(CanonicalTransaction $tx, User $user): bool
    {
        return $this->classify($tx, $user)->status() !== 'new';
    }
    ```

    ```php
    namespace Modules\Import\Public\Contracts;

     * already equals the incoming new ref, the operation is a no-op and
     * does NOT count toward the return value.
     */
    interface AppliesEnrichments
    {
        /**
         * @param list<PendingEnrichment> $enrichments
         * @return int Number of rows actually enriched (race-condition no-ops excluded)
         */
        public function __invoke(array $enrichments, User $user): int;
    ```

    `Modules/Import/Public/Actions/ApplyEnrichments.php`:

    ```php
    <?php

    declare(strict_types=1);

    namespace Modules\Import\Public\Actions;

    use Illuminate\Database\DatabaseManager;
    use Modules\Core\Models\User;
    use Modules\Core\Public\Contracts\Clock;
    use Modules\Import\Public\Contracts\AppliesEnrichments;
    use Modules\Import\Public\Dto\PendingEnrichment;

    /**
     * Applies pending cross-format enrichments produced by ImportPipeline.
     * Each enrichment is wrapped in a per-row DB transaction with
     * lockForUpdate so concurrent imports cannot race on the same row's
     * source_ref. The enriched_from JSON column accumulates the full
     * provenance trail across imports.
     */
    final class ApplyEnrichments implements AppliesEnrichments
    {
        public function __construct(
            private readonly DatabaseManager $db,
            private readonly Clock $clock,
        ) {}

        public function __invoke(array $enrichments, User $user): int
        {
            if ($enrichments === []) return 0;
            $count = 0;
            foreach ($enrichments as $e) {
                $applied = $this->applyOne($e, $user);
                if ($applied) { $count++; }
            }
            return $count;
        }

        private function applyOne(PendingEnrichment $e, User $user): bool
        {
            return (bool) $this->db->connection()->transaction(function () use ($e, $user) {
                $row = $this->db->connection()
                    ->table('transactions')
                    ->where('id', $e->existingTransactionId)
                    ->where('user_id', $user->id)
                    ->lockForUpdate()
                    ->first(['id', 'source_ref', 'enriched_from']);

                if ($row === null) return false;
                if ($row->source_ref !== null && $row->source_ref === $e->newSourceRef) {
                    return false;  // already enriched (race-condition skip)
                }

                $provenance = $this->decodeEnrichedFrom($row->enriched_from);
                $provenance[] = [
                    'format' => $e->sourceFormat,
                    'ran_at' => $this->clock->now()->toIso8601String(),
                    'import_run_id' => $e->importRunId,
                    'added' => ['source_ref'],
                ];

                $now = $this->clock->now();
                $this->db->connection()
                    ->table('transactions')
                    ->where('id', $e->existingTransactionId)
                    ->where('user_id', $user->id)
                    ->update([
                        'source_ref' => $e->newSourceRef,
                        'enriched_from' => json_encode($provenance, JSON_THROW_ON_ERROR),
                        'updated_at' => $now,
                    ]);

                return true;
            });
        }

        /**
         * @return list<array{format: string, ran_at: string, import_run_id: int, added: list<string>}>
         */
        private function decodeEnrichedFrom(?string $raw): array
        {
            if ($raw === null || $raw === '') return [];
            $decoded = json_decode($raw, associative: true, flags: JSON_THROW_ON_ERROR);
            if (! is_array($decoded)) return [];
            return array_values($decoded);
        }
    }
    ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `PendingEnrichment` JSON cache round-trip → `ApplyEnrichments` execution | The cached `PendingEnrichment` list carries integer transaction IDs. If the cache is tampered with, an attacker-controlled ID could trigger an UPDATE on the wrong row. |
| Concurrent imports of the same period from two browser tabs | Two `ImportPipeline::preview()` calls might both classify the same row as ENRICHED. `ApplyEnrichments`' lockForUpdate + ref-equality short-circuit handles this. |
| Blade-rendered `source_ref` diff | The `from` / `to` values are bank-provided strings landing inside HTML. Default `{{ }}` Blade escaping prevents XSS. |
| `enriched_from` JSON write | The provenance JSON is built server-side from internal fields (`format`, `import_run_id`, `ran_at`, `added`). No user-controlled JSON enters the column. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-05-01 | Tampering | PendingEnrichment cache round-trip carrying attacker-supplied `existingTransactionId` | mitigate | `ApplyEnrichments::applyOne()` filters by `where('user_id', $user->id)` AND `where('id', $e->existingTransactionId)`. A cross-user enrichment cannot resolve the row — `lockForUpdate()->first()` returns null and `applyOne` returns false. ApplyEnrichmentsTest covers this in the "cross-user safety" assertion. |
| T-02-05-02 | Tampering | Race: two confirms apply the same enrichment back-to-back, double-counting `enriched_count` | mitigate | `applyOne()` short-circuits when `$row->source_ref === $e->newSourceRef`, returning false. | T-02-05-03 | Information disclosure | XSS via attacker-supplied `source_ref` in the Blade diff indicator | mitigate | Blade `{{ }}` HTML-escapes by default.
