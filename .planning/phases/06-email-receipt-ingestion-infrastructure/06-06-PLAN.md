- **Backfill phase:** non-delta `/me/messages?$filter=(from/emailAddress/address eq '...') and receivedDateTime ge {windowStart}&$orderby=receivedDateTime desc&$top=100` with @odata.nextLink pagination

- **Incremental phase (Plan 07):** walk from the stored deltaLink

The Microsoft Graph SDK (microsoft/microsoft-graph ^3.1) is Kiota-generated. Its API surface is significantly different from google/apiclient — see vendor/microsoft/microsoft-graph/src/ for the request-builder shape after install. The wrapper isolates that complexity behind the four public methods above.

The /me/messages endpoint requires building a Filter expression. Use Graph SDK's request-builder fluent API:
  $graph = $this->getGraphClient($inboxId);
  $config = new \Microsoft\Graph\Generated\Me\Messages\MessagesRequestBuilderGetRequestConfiguration();
  $config->queryParameters = new \Microsoft\Graph\Generated\Me\Messages\MessagesRequestBuilderGetQueryParameters();
  $config->queryParameters->filter = "(" . implode(' or ', array_map(fn($p) => "from/emailAddress/address eq '" . addslashes($p) . "'", $senderPatterns)) . ") and receivedDateTime ge " . $windowStart->format(DATE_ISO8601);
  $config->queryParameters->orderby = ['receivedDateTime desc'];
  $config->queryParameters->top = 100;
  $response = $graph->me()->messages()->get($config)->wait();

If the SDK shape differs in the installed version, fall back to the underlying Guzzle client directly — both are acceptable. The interface (method signatures above) is the contract; the SDK choice is implementation detail.

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-06-01 | Tampering | OData injection via crafted sender_pattern containing ' or 1=1 | mitigate | known_senders.email_pattern is user-controlled but constrained at the model layer; GraphApiClient still escapes single quotes via addslashes() AND OData's single-quote-doubling rule (a literal ' inside an OData string literal is escaped as ''); validation regex on KnownSender::emailPattern at insert time rejects ' / " / ; characters |
| T-06-06-02 | Information disclosure | Microsoft Graph response includes more fields than needed | accept | The SDK return type is typed; only id/from/subject/receivedDateTime are read; other fields stay in memory but never persist |
