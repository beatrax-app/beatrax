## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-04-01 | Tampering | Single-use Microsoft refresh-token rotation race | mitigate | OAuthSecretsRepository::rotateRefreshToken (from Plan 02) is the only mutator; called inside the API client's ensureFreshToken flow with the per-inbox flock semantics of the atomic writeAtomic; tests cover a single-flight rotation under PRAGMA busy_timeout |

| T-06-04-03 | Information disclosure | refresh_token in logs on rotation | mitigate | Same posture as Plan 03 — typed exceptions carry only error codes; no Log::* call references $token |
