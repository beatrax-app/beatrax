## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Cron tick → schedule closure | runs as the queue worker user; reads ALL inboxes table (no user-scope filter — the closure runs system-wide). Inbox row leak protection: each dispatched job carries only inbox_id and runs with that inbox's existing user_id from the row. |
| IncrementalScanJob → provider API | Same posture as BackfillInboxJob — bearer token via OAuthSecretsRepository; refresh-on-401; never log token |
| Cursor-expiry fallback walk → date window | Hard 7-day window per RESEARCH Pitfall 3 / 4; not unbounded |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-07-01 | Information disclosure | Cron closure enumerating ALL inboxes leaks user_ids in logs | accept | InboxQuery returns only inbox_ids (ints); user_id is read internally inside each IncrementalScanJob from the row; no user_id ever appears in cron logs at this layer |
| T-06-07-02 | Tampering | Invalid state transition leaves a row in a contradictory state | mitigate | InboxScanStateMachine validates every transition + throws InvalidStateTransitionException; transaction wrapper ensures rollback on throw |
| T-06-07-03 | Denial of service | IncrementalScanJob backoff schedule exhausts queue retries | mitigate | tries=3 with [60,300,900] backoff per Phase 5 precedent + per RESEARCH Runtime Knobs; after $tries reached, JobFailed event listener (Plan 08 wires) transitions to error state |
| T-06-07-04 | Repudiation | Concurrent IncrementalScanJob + BackfillInboxJob for the same inbox racing on cursor updates | mitigate | ShouldBeUniqueUntilProcessing keyed on inbox_id (uniqueFor=600 for incremental, 1800 for backfill); both jobs share the same uniqueId; Laravel's unique lock blocks the second dispatch until the first completes |
| T-06-07-05 | Tampering | Cursor-expiry fallback re-fetches messages older than the window cap | accept | Fallback walks ONLY last_scan_at - 7d (not the full retention) — bounded by RESEARCH Pitfall 3 |

        $this->db->connection()->transaction(function () use ($inboxId, $newStatus, $errorMessage) {
            $conn = $this->db->connection();
            $conn->statement('PRAGMA busy_timeout = 5000');
            $row = $conn->table('inbox_scan_state')->where('inbox_id', $inboxId)->where('folder', 'INBOX')->lockForUpdate()->first();
            if ($row === null) {
                throw new RuntimeException("inbox_scan_state for inbox {$inboxId} folder INBOX not found");
            }
            $currentStatus = self::toString($row->status);
            $allowed = self::ALLOWED_TRANSITIONS[$currentStatus] ?? [];
            if (!in_array($newStatus, $allowed, true)) {
                throw new InvalidStateTransitionException("Cannot transition inbox {$inboxId} from {$currentStatus} to {$newStatus}");
            }
            $update = [
                'status' => $newStatus,
                'error_message' => $errorMessage,
                'updated_at' => $this->clock->now()->toDateTimeString(),
            ];
            // last_scan_at advances on success transitions only
            if (in_array($newStatus, ['idle', 'backfilling', 'scanning'], true)) {
                $update['last_scan_at'] = $this->clock->now()->toDateTimeString();
            }
            $conn->table('inbox_scan_state')->where('inbox_id', $inboxId)->where('folder', 'INBOX')->update($update);

      use Dispatchable, InteractsWithQueue, Queueable, SerializesModels;
      public int $tries = 3;
      public array $backoff = [60, 300, 900];
      public function __construct(public readonly int $inboxId) {}

    handle(DatabaseManager $db, Clock $clock, GmailApiClient $gmail, GraphApiClient $graph, EmlBlobStore $blobStore, MimeHeaderParser $mime, OAuthSecretsRepository $secrets, InboxScanStateMachine $sm, KnownSenderQuery $senderQuery): void:

      // 1. Load inbox + scan state row + user (raw query builder)
      $inboxRow = $db->connection()->table('inboxes')->where('id', $this->inboxId)->first();
      if ($inboxRow === null) return; // deleted
      $userId = (int) $inboxRow->user_id;
      $user = \App\Models\User::query()->where('id', $userId)->firstOrFail();
      $provider = (string) $inboxRow->provider;
      $stateRow = $db->connection()->table('inbox_scan_state')->where('inbox_id', $this->inboxId)->where('folder', 'INBOX')->first();
      if ($stateRow === null) return;

      // 2. Skip needs_reauth inboxes silently (user must hit Reconnect manually)
      if ($stateRow->status === 'needs_reauth') {
          // touch last_scan_at? — no; the timestamp staying frozen IS the signal. Just return.
          return;
      }

      // 3. Read sender patterns (Gmail uses server-side from: filter; Graph uses client-side post-filter on delta but server-side filter on fallback walk)
      $senderPatterns = array_map(fn($s) => $s->emailPattern, $senderQuery->all($user));
      if (count($senderPatterns) === 0) return;

      // 4. Transition to scanning
      try {
          $sm->applyStatus($this->inboxId, 'scanning');
      } catch (InvalidStateTransitionException $e) {
          // Already in backfilling — skip this hourly run; backfill will handle it
          return;
      }

      try {
          $newMessages = [];

          if ($provider === 'gmail') {
              $startHistoryId = (string) $stateRow->last_history_id;
              if ($startHistoryId === '') {
                  // No cursor yet — first incremental run before backfill set the cursor. Skip; the next hour's run after backfill completes will pick up.
                  $sm->applyStatus($this->inboxId, 'idle');
                  return;
              }

              try {
                  $history = $gmail->listHistory($this->inboxId, $startHistoryId);
                  $newMessages = $history['history'] ?? [];
                  $newHistoryId = $history['historyId'] ?? null;
              } catch (CursorExpiredException $e) {
                  // FALLBACK: date-bounded messages.list from last_scan_at - 7d
                  $newMessages = $this->gmailFallbackWalk($gmail, $stateRow, $senderPatterns, $clock);
                  $newHistoryId = $this->gmailExtractNewestHistoryId($newMessages) ?? $startHistoryId;
              }

              // Persist each new message via the standard .eml-then-DB ordering
              foreach ($newMessages as $msgMeta) {
                  $messageId = (string) ($msgMeta['id'] ?? $msgMeta['messages'][0]['id'] ?? '');
                  if ($messageId === '') continue;
                  $rawEml = $gmail->getRawMessage($this->inboxId, $messageId);
                  $headers = $mime->parseHeaders($rawEml);
                  $emlPath = $blobStore->pathFor($userId, $this->inboxId, $headers->internalDate, $messageId);
                  $blobStore->put($emlPath, $rawEml);
                  try {
                      $db->connection()->transaction(function() use (...) {
                          $db->connection()->statement('PRAGMA busy_timeout = 5000');
                          $db->connection()->table('inbox_messages')->insertOrIgnore([/* same shape as backfill */]);
                      });
                  } catch (\Throwable $e) {
                      $blobStore->delete($emlPath);
                      throw $e;
                  }
              }

              // Persist new cursor
              if ($newHistoryId !== null) {
                  $db->connection()->table('inbox_scan_state')
                      ->where('inbox_id', $this->inboxId)->where('folder', 'INBOX')
                      ->update(['last_history_id' => $newHistoryId, 'updated_at' => $clock->now()->toDateTimeString()]);
              }
          }

          if ($provider === 'microsoft') {
              $deltaLink = (string) $stateRow->last_delta_link;
              if ($deltaLink === '') {
                  $sm->applyStatus($this->inboxId, 'idle');
                  return;
              }

              try {
                  $page = $graph->deltaPage($this->inboxId, $deltaLink);
                  $messages = $page['messages'] ?? [];
                  $newDeltaLink = $page['deltaLink'] ?? $page['nextLink'] ?? $deltaLink;
              } catch (CursorExpiredException $e) {
                  $messages = $this->graphFallbackWalk($graph, $stateRow, $senderPatterns, $clock);
                  // After fallback, re-baseline via a fresh deltaPage(null)
                  $baseline = $graph->deltaPage($this->inboxId, null);
                  $newDeltaLink = $baseline['deltaLink'] ?? '';
              }

              // Client-side post-filter on delta messages (Graph delta doesn't support from/ $filter)
              foreach ($messages as $msgMeta) {
                  $senderAddr = strtolower($msgMeta['fromAddress'] ?? '');
                  $matched = false;
                  foreach ($senderPatterns as $pattern) {
                      $p = strtolower($pattern);
                      if (str_starts_with($p, '@')) {
                          if (str_ends_with($senderAddr, $p)) { $matched = true; break; }
                      } else {
                          if (str_contains($senderAddr, $p)) { $matched = true; break; }
                      }
                  }
                  if (!$matched) continue;

                  $messageId = $msgMeta['id'];
                  $rawEml = $graph->getRawMessage($this->inboxId, $messageId);
                  $internalDate = new \DateTimeImmutable($msgMeta['receivedDateTime']);
