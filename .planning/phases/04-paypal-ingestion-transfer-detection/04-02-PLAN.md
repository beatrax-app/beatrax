`PaypalTransactionRollup` algorithm (three-pass — verbatim from RESEARCH.md Pattern 1):
```
Pass 1: Build $byTxnId index. Skip event types where classify() === 'skip'; bump $skippedHoldCount.
Pass 2: Partition rows by Reference Txn ID — parent (RefId empty OR equals own TxnId) vs child (RefId equals another row's TxnId).
        Orphan children (parent absent from file) become standalone parents; bump $orphanChildCount.
Pass 3: For each parent, fold children into ONE SourceTransactionDto:
        - amountMinor / currency: foreign-currency leg of any child-fx sibling, else parent's Gross
        - settledAmountMinor / settledCurrency: EUR leg of child-fx pair, else null
        - fxRateUsed: ALWAYS null (NormalizeStage derives per Phase 3 D-39)
        - rawPayload: { format: 'paypal-csv', events: [{ type, row }, ...] }
        - sourceRef: parent's Transaction ID (D-64)
        - sourceRowIndex: canonical-row scope, monotonically increasing 0..N
        - counterpartyIban: extracted from the parent row's IBAN column if present, else null (Wave 0 (f) reports the column)
        - counterpartyName: parent's merchant/Name column (anonymised in fixture to KAARTHOUDER)
        - description: e.g., "Express Checkout Payment / Netflix.com" (parent eventType / counterpartyName when available)
```
FX-direction safety net (Pitfall 2): `if ($row['Currency'] !== 'EUR') { /* foreign leg */ }` — never pick "the second row" arbitrarily.

```php
public function rollup(array $rawRows, string $language): array
{
    $this->resetCounters();

    // Pass 1: index by Transaction ID, drop skipped event types.
    /** @var array<string, list<array<string, string>>> $byTxnId */
    $byTxnId = [];
    /** @var list<array<string, string>> $filtered */
    $filtered = [];
    foreach ($rawRows as $row) {
        $eventType = $this->columns->value('type', $language, $row) ?? '';
        if ($eventType === '') {
            continue;
        }
        $action = $this->events->classify($eventType, $language);
        if ($action === 'skip') {
            $this->skippedHoldCount++;
            continue;
        }
        $filtered[] = $row;
        $txnId = $this->columns->value('transactionId', $language, $row) ?? '';
        if ($txnId !== '') {
            $byTxnId[$txnId][] = $row;
        }
    }

    // Pass 2: partition by parent vs child via Reference Txn ID.
    /** @var array<string, list<array<string, string>>> $childrenByParent */
    $childrenByParent = [];
    /** @var list<array<string, string>> $parents */
    $parents = [];
    foreach ($filtered as $row) {
        $txnId = $this->columns->value('transactionId', $language, $row) ?? '';
        $refId = $this->columns->value('referenceTxnId', $language, $row) ?? '';
        $isChild = $refId !== '' && $refId !== $txnId && isset($byTxnId[$refId]);
        if ($isChild) {
            $childrenByParent[$refId][] = $row;
        } elseif ($refId !== '' && $refId !== $txnId && ! isset($byTxnId[$refId])) {
            // Orphan child: parent absent from file → standalone parent.
            $this->orphanChildCount++;
            $parents[] = $row;
        } else {
            $parents[] = $row;
        }
    }

    // Pass 3: fold each parent's children into ONE SourceTransactionDto.
    /** @var list<SourceTransactionDto> $rolledUp */
    $rolledUp = [];
    $canonicalIndex = 0;
    foreach ($parents as $parentRow) {
        $parentTxnId = $this->columns->value('transactionId', $language, $parentRow) ?? '';
        $children = $childrenByParent[$parentTxnId] ?? [];

        // FX-direction safety net (Pitfall 2): if any child is a child-fx, identify
        // foreign vs EUR legs by Currency column, NOT by row order.
        $nativeAmountMinor = $this->amounts->parseMinor($this->columns->value('gross', $language, $parentRow) ?? '0.00');
        $nativeCurrency = $this->columns->value('currency', $language, $parentRow) ?? 'EUR';
        $settledAmountMinor = null;
        $settledCurrency = null;

        foreach ($children as $childRow) {
            $childAction = $this->events->classify(
                $this->columns->value('type', $language, $childRow) ?? '',
                $language
            );
            if ($childAction === 'child-fx') {
                $childCurrency = $this->columns->value('currency', $language, $childRow) ?? 'EUR';
                $childAmountMinor = $this->amounts->parseMinor($this->columns->value('gross', $language, $childRow) ?? '0.00');
                if ($childCurrency === 'EUR' && $nativeCurrency !== 'EUR') {
                    // child = EUR settled leg; parent already holds foreign-currency native amount
                    $settledAmountMinor = $childAmountMinor;
                    $settledCurrency = $childCurrency;
                } elseif ($childCurrency !== 'EUR' && $nativeCurrency === 'EUR') {
                    // Swap: parent's "Gross" is actually the EUR settled leg; child holds the foreign native leg
                    $settledAmountMinor = $nativeAmountMinor;
                    $settledCurrency = $nativeCurrency;
                    $nativeAmountMinor = $childAmountMinor;
                    $nativeCurrency = $childCurrency;
                }
                // Else: both legs same currency — degenerate; skip the fold.
            }
            // child-fee is captured in rawPayload but does not contribute to amount.
        }

        $bookedAt = $this->dates->parse($this->columns->value('date', $language, $parentRow) ?? '');

        $eventManifest = [
            ['type' => $this->columns->value('type', $language, $parentRow), 'row' => $parentRow],
        ];
        foreach ($children as $childRow) {
            $eventManifest[] = ['type' => $this->columns->value('type', $language, $childRow), 'row' => $childRow];
        }

        $rolledUp[] = new SourceTransactionDto(
            bookedAt: $bookedAt,
            postedAt: $bookedAt,
            valueDate: $bookedAt,
            ownIban: 'PAYPAL',
            counterpartyIban: $this->columns->value('counterpartyIban', $language, $parentRow),
            counterpartyName: $this->columns->value('counterpartyName', $language, $parentRow),
            currency: $nativeCurrency,
            amountMinor: $nativeAmountMinor,
            sourceRef: $parentTxnId,
            description: trim(sprintf(
                '%s / %s',
                $this->columns->value('type', $language, $parentRow) ?? '',
                $this->columns->value('counterpartyName', $language, $parentRow) ?? ''
            ), ' /'),
            rawPayload: [
                'format' => 'paypal-csv',
                'events' => $eventManifest,
            ],
            sourceRowIndex: $canonicalIndex++,
            settledAmountMinor: $settledAmountMinor,
            settledCurrency: $settledCurrency,
            fxRateUsed: null,
        );
    }

    return $rolledUp;
}
```

```php
final class PaypalCsvAdapter implements SourceAdapter
{
    private ?StatementSummaryData $lastStatementMetadata = null;

    public function __construct(
        private readonly HeaderSniffer $sniffer,
        private readonly PaypalAmountParser $amounts,
        private readonly PaypalDateParser $dates,
        private readonly PaypalCsvEventTypeMap $eventTypes,
        private readonly PaypalCsvColumnMap $columns,
        private readonly PaypalTransactionRollup $rollup,

    public function format(): string
    {
        return PaypalCsvLanguageProfile::FORMAT;
    }

    public function statementMetadata(): ?StatementSummaryData
    {
        return $this->lastStatementMetadata;
    }

    public function parse(string $localPath, AccountResolver $accounts): Generator
    {
        $this->sniffer->sniff($localPath, PaypalCsvLanguageProfile::FORMAT);
        $this->lastStatementMetadata = null;

        $reader = Reader::from($localPath, 'r');
        $reader->setDelimiter(PaypalCsvLanguageProfile::DELIMITER);
        $reader->setEscape('');
        $reader->setHeaderOffset(0);
        CharsetConverter::addTo($reader, PaypalCsvLanguageProfile::SOURCE_ENCODING, 'UTF-8');

        $headerColumns = $reader->getHeader();
        $languageProfile = PaypalCsvLanguageProfile::detect($headerColumns);
        if ($languageProfile === null) {
            throw new UnsupportedPaypalCsvLanguageException(
                'PayPal CSV header tokens did not match any registered language profile. Supported: '
                .implode(',', PaypalCsvLanguageProfile::supported())
            );
        }
        $language = $languageProfile->detected();

        // Buffer all raw rows for the rollup walker (D-61).
        /** @var list<array<string, string>> $rawRows */
        $rawRows = [];
        foreach ($reader->getRecords() as $record) {
            $rawRows[] = $record;
        }

        // Synthetic-IBAN account resolution (D-66) — mirrors Phase 3 IcsPdfAdapter.
        $accounts->resolve('PAYPAL');

        $rolledUp = $this->rollup->rollup($rawRows, $language);

        $bookedDates = [];
        $netSumMinor = 0;
        $count = 0;
        foreach ($rolledUp as $dto) {
            yield $dto;
            $bookedDates[] = $dto->bookedAt;
            $netSumMinor += $dto->amountMinor;
            $count++;
        }

        // Stateful summary capture — mirrors Ics lines 153–159.
        if ($bookedDates !== []) {
            $minBookedAt = min($bookedDates);
            $maxBookedAt = max($bookedDates);
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Wizard upload → adapter | PayPal CSV byte input crosses; `HeaderSniffer::sniffPaypalCsv()` is the validation gate. Anything past the sniffer is treated as "shape-validated CSV with a known language profile". |
| Adapter → pipeline → transactions table | Rolled-up DTOs flow through normal Phase 1 / Phase 2 / Phase 3 pipeline; PayPal-specific quirks (synthetic IBAN, raw payload event manifest) ride on existing schema slots. |
| User-A vs User-B PayPal accounts | `Account` table's `(user_id, iban)` UNIQUE — both users can have `iban = 'PAYPAL'` without collision; every `AccountResolver::resolve()` call scopes to the authenticated user. |
