1. Reads the input CSV path from `$argv[1]`, writes to STDOUT (so the caller can redirect). Falls back to clear error message if no argument.
2. Uses native PHP `fgetcsv()` / `fputcsv()` to parse + emit (zero deps).
3. **TWO-PASS DETERMINISTIC COUNTER MAP for Transaction ID and Reference Txn ID (per D-58 + Pitfall 5):**
   - Pass 1: scan every row, collect every distinct non-empty value in both the `Transaction ID` column AND the `Reference Txn ID` column into a single set `$realToSynthetic`. Assign each real ID a synthetic value `O-<zero-padded-17-digit-counter>` (e.g. `O-00000000000000001`). Counter starts at 1.
   - Pass 2: rewrite every row through the same map. The same real ID anywhere in the file maps to the same synthetic. Parent-child links survive because both columns resolve through the same map.
4. Other redactions per D-58 (apply in a row-rewrite pass alongside step 3):
   - Email addresses (any column containing `@` and a `.`): replace with `kaarthouder@example.test`.
   - Personal-name columns (`Name`, `From Email Address`'s display name fragment if present, `To Email Address` likewise): replace with literal `KAARTHOUDER`.

   - Address-shaped columns (`Address`, `Address 1`, `Address 2`, `Country Code`, etc.): drop to empty string.
   - ZIP / postal-code columns: zero out (`00000` or `0000 AA` style).

5. **PRESERVE VERBATIM:** all `Date`, `Time`, `Type` / event-type strings, `Currency`, `Gross`, `Fee`, `Net`, `Balance`, merchant name strings, item / description columns, status, every numeric / monetary / date / event-type cell.
