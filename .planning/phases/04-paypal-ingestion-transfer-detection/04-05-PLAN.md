**BoundaryArchTest::noPaypalApiRoute** — Wave 4 deliverable:

The existing `tests/Contracts/BoundaryArchTest.php` is a Pest test file with grep-style assertions (already in use per `UserIdColumnArchTest`'s pattern). Add a new test:

```php
it('does not allow a paypal-api route or class to exist (ING-09 deferral)', function () {
    // ING-09 / D-79: PayPal Reporting API is deferred. Defensive arch invariant
    // — if a future task accidentally lands a paypal-api adapter or a
    // PaypalReportingApi class, this test fails loudly.
    $hits = [];

    foreach (['routes', 'Modules'] as $root) {
        $absoluteRoot = base_path($root);
        if (! is_dir($absoluteRoot)) {
            continue;
        }
        $finder = new \RecursiveIteratorIterator(
            new \RecursiveDirectoryIterator($absoluteRoot, \RecursiveDirectoryIterator::SKIP_DOTS)
        );
        foreach ($finder as $file) {
            if (! $file->isFile()) {
                continue;
            }
            $path = $file->getPathname();
            if (preg_match('/\.(php|blade\.php)$/', $path) !== 1) {
                continue;
            }
            $contents = (string) file_get_contents($path);
            // Strip comments to avoid false positives in PHPDoc / inline comments.
            $stripped = preg_replace('#/\*.*?\*/|//[^\n]*#s', '', $contents) ?? $contents;
            if (preg_match('/PaypalApiAdapter|PaypalReportingApi|paypal-api/i', $stripped) === 1) {
                $hits[] = $path;
            }
        }
    }

    expect($hits)->toBe([], sprintf(
        "ING-09 is deferred; no paypal-api route or class should exist.\nFound in:\n  %s",
        implode("\n  ", $hits)
    ));
});
```

The test ignores comments via a regex strip so legitimate documentation-style references in PHPDoc blocks (e.g. `/** ING-09 is deferred — see REQUIREMENTS.md */`) do NOT trigger the failure. The defensive grep matches against three literal patterns: `PaypalApiAdapter`, `PaypalReportingApi`, `paypal-api`.

**Important:** The grep also scans `04-*-PLAN.md` style references — but the `routes/` and `Modules/` scope keeps it inside production code only. `.planning/` is intentionally out of scope (the planning docs reference ING-09 as part of legitimate Wave 4 wording).
