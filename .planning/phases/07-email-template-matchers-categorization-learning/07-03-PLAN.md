ICS receipt extraction anchors (RESEARCH §"ICS Cards Receipt Matcher" lines 944-974):
  - merchant: text within HTML table cell or following label /(merchant|verkoper):\s*(.+)/im — strip HTML tags first via $parsed->htmlBody chain (ICS receipts are mostly HTML)
  - amount: /€\s*([0-9.,]+)/ — Dutch comma decimal; brick/money parse
  - card_last4: /eindigend op\s*([0-9]{4})/i OR /kaart\s*\*{4}\s*([0-9]{4})/i — when matched, populates ChainHintPayload\FundedByCardPayload
  - reference: /(referentienummer|autorisatiecode):\s*([A-Z0-9]+)/im — 4-6 chars typically

Google Play receipt anchors:
  - order id: /GPA\.[0-9]{4}-[0-9]{4}-[0-9]{4}-[0-9]{5}/ — strict format; missing -> unmatched
  - amount + currency: native USD line + (sometimes) settled EUR line — emit both as amountMinor/currency (USD) + settledAmountMinor/settledCurrency (EUR) per Phase 3 D-42 dual-amount pattern when EUR is present
  - merchant: from "Total" line or first item description
  - refund detection: subject contains "refund" -> negative amount AND chainHint=RefundOfPayload(originalOrderId) OR return MatchOutcomeDto.skipped('googleplay-refund-v2') for v1

ChainHintDetected event (Wave 0 contract):
  public readonly int sourceTransactionId
  public readonly string hintType  // 'funded_by_card'|'refund_of'
  public readonly object hintPayload  // FundedByCardPayload|RefundOfPayload
  public readonly string evidence
  public readonly int userId

RecordReceipt dispatches the event AFTER it persists the canonical row so sourceTransactionId is the just-inserted row id; ParseStage runs pre-persistence and never dispatches this event.

ChainLink model (Phase 5): scope is (user_id, from_transaction_id, to_transaction_id, link_type, state, confidence, evidence). The new listener writes a CANDIDATE row (state='candidate', link_type='funded_by_card_hint', confidence=0.5) keyed on the source transaction id, with to_transaction_id=null + evidence carrying the card_last4. Phase 5's existing resolver later promotes it once a matching ICS card_statement row binds.
