## Manual-rename learning-rule shape

| Option | Description | Selected |
|--------|-------------|----------|
| Exact match on raw description (Recommended for v1) | Only renames identical future descriptions. Zero false positives, but Shell on a different terminal won't get the same name automatically. | |
| Prefix match (e.g. 'BCK*SHELL PIETER*') | Catches future variations with the same prefix. Faster learning curve but risk of over-matching. | |
| Smart auto-generalize — strip terminal IDs and trailing digits | Detect terminal-ID patterns and auto-suggest a generalized pattern. Most powerful but adds heuristic complexity. | ✓ |

**User's choice:** Smart auto-generalize.
**Notes:** Implementation per CONTEXT.md D-08 — both an exact `pattern` and a `generalized_pattern` stored per alias; D-10 — `PatternGeneralizer` heuristic strips trailing terminal IDs and digit runs; popover renders the generalized preview so the user sees what they're agreeing to; D-11 — exact match takes precedence over generalized match at render time.
