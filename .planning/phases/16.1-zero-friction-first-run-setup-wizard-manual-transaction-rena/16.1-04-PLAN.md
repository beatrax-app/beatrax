<objective>
Wire the click-italic rename flow on the import preview row: the italic raw-description text IS the click target (no pencil button); clicking opens a Flux modal popover with a checkbox "Remember "..." as this name"; saving writes a `merchant_aliases` row, optionally seeds a `categorization_rules` row, and the next render shows the user-chosen friendly name. Implements D-08 / D-09 / D-10 / D-11 plus RENAME-01 / RENAME-02 / RENAME-03.

Depends on Plan 03b because the wizard's FirstImportStep mounts UploadWizard inline and that blade is touched by this plan to wire `.desc-fallback`. Landing Plan 04 before 03b would force a second touch on upload-wizard.blade.php; the dependency ordering avoids that.

Purpose: The italic fallback name is the single biggest UX irritation in the current import preview (raw bank codes like `BCK*SHELL PIETER NIEUW *0123` are unintelligible). The rename flow turns one-time mental decoding into a permanent personal mapping — the user pays the cost once, every future import benefits.
