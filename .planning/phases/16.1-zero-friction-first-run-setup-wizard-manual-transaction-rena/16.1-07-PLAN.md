**Service `Modules/Import/Internal/Services/LongestCommonPrefix.php`** — pure-fn class. Constructor empty. Method `compute(array $patterns): string`:
- if count < 2 → throw `\InvalidArgumentException`
- lower-case the first pattern; if empty → return ''
- iterate the rest; mb-safe character-by-character common prefix
- if any pattern returns 0 min-length → return ''
- final result = trim(mb_substr(first, 0, $minLen))
- if mb_strlen(result) < 4 → return '' (per Pitfall 6)
- else return result

PHPDoc describes the degenerate-input rejection (size-1, empty, < 4 chars).

**Action `Modules/Import/Public/Actions/MergeMerchantAliases.php`** — Constructor DI: `private readonly \Illuminate\Database\DatabaseManager $db, private readonly \Illuminate\Support\DateFactory $dates`. `__invoke(User $user, list<int> $aliasIds, string $friendlyName, string $generalizedPattern): MerchantAlias`:
- Open a `$this->db->connection()->transaction(...)`
- Load rows via `MerchantAlias::query()->where('user_id', $user->id)->whereIn('id', $aliasIds)->get()`
- If row count != requested count → throw NotFoundHttpException (404-not-403)
- If row count < 2 → throw `\InvalidArgumentException`
- surviving = lowest-id row; absorbed = the rest
- `$mergedFrom = $absorbed->map(fn ($r) => ['pattern' => $r->pattern, 'generalized_pattern' => $r->generalized_pattern, 'friendly_name' => $r->friendly_name, 'merged_at' => $this->dates->now()->toIso8601String()])->values()->all();`
- update surviving with the new friendly/generalized + merged_from
- delete absorbed rows
- return surviving->fresh()

Per rule C-1: NEVER call `now()` — use the injected DateFactory.
