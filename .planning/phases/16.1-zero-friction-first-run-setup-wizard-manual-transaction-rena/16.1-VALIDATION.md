## Sampling Rate

Per RESEARCH.md §"Sampling Rate":

- **After every task commit:** run ONLY the Pest test file mapped to the REQ-ID touched in that task (`vendor/bin/pest <file>` — typically <2s). Per-task `<verify>` blocks use this narrow scope.
- **After the LAST task of each plan (close-out gate):** run the full triple-gate (`composer test && composer analyse && composer format:check`). Each plan's final task includes this in its `<verify>` block per the W-8 revision fix.
- **After every wave merge:** the full triple-gate runs again as part of the next plan's close-out OR by manual invocation.
- **Before `/gsd:verify-work`:** the full triple-gate must be green.
- **Max feedback latency (per-task quick scope):** <60s
- **Max feedback latency (per-plan close-out):** ~5 min
