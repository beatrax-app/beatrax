<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| composer install | new third-party dependency (dompdf) — supply-chain surface |
| free-text note → PDF HTML | user-controlled text rendered into a document |
| dompdf → network | a PDF engine that could fetch remote assets if misconfigured |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-SC | Tampering | dompdf composer install | mitigate | Blocking legitimacy checkpoint before `composer require`; verified on packagist/github; `[ASSUMED]` not auto-approvable |
| T-07-08 | Tampering | free-text note XSS in PDF | mitigate | HTML-escape all note/description with `{{ }}`/`e()`; tested with `<script>` payload (Task 2) |
| T-07-09 | Information disclosure | dompdf SSRF via remote URL | mitigate | `isRemoteEnabled=false` on Options; asserted in test (Task 2) |
| T-07-10 | Information disclosure | export contains another user's data | mitigate | exporters read only `TaxYearQuery::forUser($user->id, ...)` which is user-scoped (Plan 02) |
</threat_model>
