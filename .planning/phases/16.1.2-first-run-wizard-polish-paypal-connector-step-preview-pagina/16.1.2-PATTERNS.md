**Submit pattern** — adapted from `ConnectBankStep::submit()` lines 169–294. Key differences:
- No CSV-branch guard (PayPal exports one format only)
- Replace the per-file account-create block (lines 220–280) with a single call to `EnsurePaypalAccountAction`
- Stash a **single int** (`paypal_import_run_id`), not an array — mirrors bank, not card
- Re-preview from the stored path only when the action reports it created the account (so existing-account submits skip the second pipeline pass)

```php
public function submit(
    RunsImports $importer,
    EnsurePaypalAccountAction $ensurePaypalAccount,
    CurrentUser $currentUser,
    LoggerInterface $logger,
    Application $app,
    DatabaseManager $db,
): void {
    $this->uploadError = null;
    $this->validate();

    if ($this->activityCsv === null) {
        return;
    }

    $user = $currentUser->user();
    $tmp = $this->activityCsv->getRealPath();
    $originalFilename = $this->sanitiseFilename($this->activityCsv->getClientOriginalName());

    try {
        $result = $importer->runFromUpload($tmp, $this->selectedFormat, $user, $originalFilename);
    } catch (Throwable $e) {
        $logger->error('ConnectPaypalStep: import preview failed.', [
            'source_format' => $this->selectedFormat,
            'filename' => $originalFilename,
            'exception_class' => $e::class,
            'exception_message' => $e->getMessage(),
            'exception_trace' => SafeTrace::cap($e, $app->basePath()),
        ]);
        // UnsupportedPaypalCsvShapeException bubbles here — friendly toast copy
        // shipped in 16.1.1-04 surfaces via the inline error band (D-08).
        $this->uploadError = 'Could not read this file. The full error is in /dev/logs.';

        return;
    }

    // Idempotent PayPal account create. Action returns true iff it actually
    // INSERTed; we only re-preview on a real create so the second call
    // doesn't fire on every subsequent submit by a user with an existing
    // PayPal account.
    $created = ($ensurePaypalAccount)($user);
    if ($created) {
        /** @var ImportRun|null $run */
        $run = ImportRun::query()
            ->where('id', $result->importRunId)
            ->where('user_id', $user->id)
            ->first();
        if ($run !== null && file_exists($run->raw_file_path)) {
            try {
                $importer->runFromUpload(
                    $run->raw_file_path,
                    $this->selectedFormat,
                    $user,
                    basename($run->raw_file_path),
                );
            } catch (Throwable $e) {
                $logger->warning('ConnectPaypalStep: re-preview after PayPal account creation failed.', [
                    'import_run_id' => $result->importRunId,
                    'exception_class' => $e::class,
                    'exception_message' => $e->getMessage(),
                    'exception_trace' => SafeTrace::cap($e, $app->basePath()),
                ]);
            }
        }
    }

    $progress = WizardProgress::query()
        ->where('user_id', $user->id)
        ->where('step_key', 'connect-paypal')
        ->first();

    if ($progress !== null) {
        $data = $progress->data ?? [];
        $data['paypal_import_run_id'] = $result->importRunId;
        $progress->update(['data' => $data]);
    }

    $this->dispatch('wizard.step.completed');
}
```

private function sanitiseFilename(string $original): string
{
    $stem = pathinfo($original, PATHINFO_FILENAME);
    $safe = preg_replace('/[^A-Za-z0-9_-]+/', '_', $stem);

**Suggested target shape:**

```php
<?php

declare(strict_types=1);

namespace Modules\Import\Public\Actions;

use Illuminate\Database\DatabaseManager;
use Modules\Core\Models\User;
use Modules\Ledger\Models\Account;

/**
 * Ensures the user has a synthetic PayPal `accounts` row keyed on
 * iban `'PAYPAL'`, kind `'paypal'`, EUR-settled. Mirrors the ICS card
 * auto-create pattern in ConnectCardStep — the synthetic-IBAN account
 * is what the PaypalCsvAdapter resolves every imported row against, so
 * without it every preview row would be an unknown-IBAN error and the
 * statement_summaries writer would never fire (which blocks the
 * starting-balance detector on the FirstImportStep).
 *
 * Returns `true` when an INSERT happened (caller should re-preview),
 * `false` when the account already existed (caller can skip the
 * re-preview pass).
 *
 * The raw Query Builder `->table('accounts')->exists()` check sidesteps
 * the PHPStan strict-rules `staticMethod.dynamicCall` finding that the
 * Eloquent `Account::query()->exists()` form triggers — same pattern
 * ConnectCardStep:192 uses.
 */
final readonly class EnsurePaypalAccountAction
{
    /** Synthetic own-IBAN — mirrors PreviewWizard::PAYPAL_OWN_IBAN.
     *  Kept in sync by an arch test the planner schedules alongside. */
    public const string PAYPAL_OWN_IBAN = 'PAYPAL';

    public function __construct(private DatabaseManager $db) {}

    public function __invoke(User $user): bool
    {
        $exists = $this->db->connection()
            ->table('accounts')
            ->where('user_id', $user->id)
            ->where('iban', self::PAYPAL_OWN_IBAN)
            ->exists();

        if ($exists) {
            return false;
        }

        Account::query()->create([
            'user_id' => $user->id,
            'name' => 'PayPal',
            'slug' => 'paypal-paypal',
            'kind' => 'paypal',
            'iban' => self::PAYPAL_OWN_IBAN,
            'default_currency' => 'EUR',
        ]);

        return true;
    }
}
```

**Name decision:** the existing PreviewWizard path used `$this->paypalAccountName` (user-typed) plus `$slugBody.'-paypal'`. For the **wizard auto-create path** the user has not been prompted, so the action defaults to `name = 'PayPal'`, `slug = 'paypal-paypal'`. Planner may want to drop the slug pattern entirely (let the user rename later from Settings, identical to bank auto-create at `ConnectBankStep.php:240-247`).

**Constructor-DI rule:** action is `final readonly`, single `DatabaseManager` collaborator, no facades, no helpers. Per memory `feedback_laravel_di_only`.
