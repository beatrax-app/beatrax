## PayPal step shape

### Q1 — Position in wizard order

| Option | Description | Selected |
|--------|-------------|----------|
| Between card and email | `welcome → connect-bank → connect-card → connect-paypal → connect-email → first-import → done`. Clusters file uploads (bank, card, paypal), then email (OAuth/receipts). | |
| Between email and first-import | `welcome → connect-bank → connect-card → connect-email → connect-paypal → first-import → done`. Literal reading of the handover. | |

## Preview pagination affordance

### Q1 — Pagination strategy

| Option | Description | Selected |
|--------|-------------|----------|
| Expand-in-place per section | Footer becomes "Show all 137 rows" link; click re-runs query for that section with no cap. Handover recommendation. | |
| Cursor "Load 25 more" | Footer becomes "Load 25 more" button. Each click extends sampleRows by next chunk. Lighter on memory. | ✓ |
| Toggle Sample / All globally | Single top-level toggle re-runs query with SAMPLE_ROW_LIMIT → PHP_INT_MAX globally. | |

**User's choice:** Cursor "Load 25 more".
**Captured as:** D-09 in CONTEXT.md.

### Q2 — Chunk size + cursor scope

| Option | Description | Selected |
|--------|-------------|----------|
| Chunk = 25, per-section cursor | Each click bumps the section's row cap by 25 (5 → 30 → 55 …). Cursor in `expandedRowCount: array<string,int>` keyed by source_format. | ✓ |
| Chunk = 50, per-section cursor | Same shape, larger step. | |
| Chunk = 25, page-style cursor | Proper cursor pagination (after-id / offset) so section only holds 25 rows in memory; prev/next controls. | |

**User's choice:** Chunk = 25, per-section cursor.
**Captured as:** D-10, D-11, D-12 in CONTEXT.md.

### Q3 — Button copy

| Option | Description | Selected |
|--------|-------------|----------|
| "Load 25 more" → "· 137 total" | Stays "Load 25 more" until fewer than 25 remain, then "Load remaining 12 rows". Subline shows running "· 137 total". | |
| "Show 25 more rows" / "Show all 137" | Primary button + secondary "Show all" link. Escape hatch without losing incremental as default. | |
| Just "Load more (132 remaining)" | Minimal: single affordance, no "show all" shortcut. | ✓ |

**User's choice:** Just "Load more (132 remaining)".
**Captured as:** D-09 + Specific Ideas section in CONTEXT.md.
