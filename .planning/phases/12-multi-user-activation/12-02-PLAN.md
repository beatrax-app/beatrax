## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| application → SQLite | OAuth secrets pass through encrypted cast; plaintext exists only inside Eloquent attribute layer |
| operator → DB on disk | If an attacker copies `database.sqlite`, encrypted secrets remain ciphertext (assuming `APP_KEY` not also stolen) |
| migration → existing data | The dev user row's email is dropped without remediation; the developer re-signs up post-migration |
