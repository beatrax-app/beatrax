<objective>
Ship the first-user signup ceremony (D-03, D-04, D-06, D-07, D-11): generate 10 recovery codes with the D-11 phone-readable alphabet, atomically create the User row + 10 bcrypt-hashed code rows inside a transaction race-protected by the `User::count() === 0` gate, auto-log-in the new user, redirect to the inline display page, gate the `Continue` button on a checkbox, and offer a `.txt` download with the exact filename `diederik-recovery-codes-<lowercase-username>.txt`.

Purpose: Without this plan, a fresh install has no way for the developer to bootstrap. The signup ceremony is the ONLY public auth surface in Phase 12 — every subsequent user is created by the owner via Plan 12-05's AddUserAction (deferred to a later plan; first-user covers the demoable end-state for this slice).

Output: A fresh `php artisan migrate:fresh` install → visit `/signup` → create user → see 10 codes → download `.txt` → check the box → click `Continue to diederik` → land on the dashboard logged in as the new (developer) user.
</objective>

```
final class RecoveryCodesDisplay extends Component
  public bool $confirmed = false;
  public bool $downloadShown = false;
  protected array $codes = [];

  mount(SessionContract $session): void
    $codes = $session->get('auth.signup.recovery_codes_plain');
    if ($codes === null) { throw new NotFoundHttpException; }  // codes ceremony only shown once; navigating back returns 404
    $this->codes = $codes;
    // Do NOT clear session yet — clear in `continue()` so refresh works during display

  download(RecoveryCodeFormatter $formatter, CurrentUser $currentUser): StreamedResponse
    $username = $currentUser->user()->username;
    return response()->streamDownload(
        function () use ($formatter): void { echo $formatter->format($this->codes); },
        $formatter->filenameFor($username),
        ['Content-Type' => 'text/plain; charset=UTF-8']
    );

  continue_(SessionContract $session, UrlGenerator $urls): void
    if (! $this->confirmed) return;  // safety; UI also disables the button
    $session->forget('auth.signup.recovery_codes_plain');
    $this->redirect($urls->route('dashboard'), navigate: false);

  render(...) — extends('layouts.app', ['title' => 'Save these recovery codes · diederik'])
```
