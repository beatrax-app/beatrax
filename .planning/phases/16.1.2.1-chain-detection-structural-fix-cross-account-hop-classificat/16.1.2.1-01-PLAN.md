<objective>
Close the structural gap that produces 100% uncategorized first imports: ship a default categorization-rule seed set so a fresh user automatically gets ~80+ universal-merchant rules and so the existing `ApplyAutoCategoryStage` (already wired into `ImportPipeline`) actually produces categorized transactions during ingestion.

Purpose: Without this seed, `categorization_rules` is empty on every fresh install and `ApplyAutoCategoryStage` runs but assigns zero categories — leaving every imported row in the triage queue. The seed is per-user (matching the existing `RuleEvaluator` scoping which has no NULL handling) and is installed via the same `UserInstalled` listener pattern that already runs `SeedDefaultCategoryTree`.

Output: A new per-user seeder + listener wired in `CategorizationServiceProvider`, a native PHP fixture of seed rules sourced verbatim from `SEED-RULES.md`, idempotent insertion semantics that lock `firstOrCreate` (not `updateOrCreate`) at the test level, and Pest coverage proving both the seed completeness, the end-to-end import categorization outcome, AND the ≥40% gate against a live-distribution-sampled fixture.
</objective>
