## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser ?currency= URL param → Livewire property | `#[Url(as: 'currency')]` accepts arbitrary strings; the component must defensively map only known values |
| Livewire property → TransactionListQuery $currency arg | The query's signature accepts ?string $currency; an unknown value silently filters to "no match" (empty list) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05-01 | Tampering | currency wire-property | mitigate | render() explicitly maps only `'eur'` → `'EUR'`, EVERY other value → null. A `?currency=garbage` URL silently falls into the "original" path (native projection). No invalid value reaches the SQL layer. |
| T-03-05-02 | Information Disclosure | secondaryAmount on /transactions in eur mode | mitigate | TransactionListQuery only projects secondary_* columns when $currency is null (original mode). In eur mode the SELECT does not include the secondary pair, so the API surface accidentally exposing the other-currency leg is impossible. |
| T-03-05-03 | Spoofing | Flux segmented control CSRF | mitigate | Livewire-native CSRF on every wire:model.live update. Phase 1 invariant — no new mitigation needed. |
</threat_model>
