    - Of the matching backup files, keep:
      - The 7 most-recent daily files (by parsed date+time, descending). "Daily" here means any backup — the 7 most recent files regardless of weekday.
      - PLUS the 4 most-recent Sunday-dated weekly files (parsed date.dayOfWeek === Sunday). Some files may satisfy both rules; the union is the set kept.
    - Everything else from the matching set is OMITTED from the return value (= scheduled for deletion by the caller).
    - Sunday-day-of-week is computed via `CarbonImmutable::parse("Y-m-d", $matchDate)->dayOfWeek === CarbonImmutable::SUNDAY` — but Carbon's SUNDAY constant equals 0. Verify against your installed Carbon version by reading from `CarbonImmutable::SUNDAY` rather than hardcoding 0.
    - Edge cases the Pest dataset MUST cover:
      - 0 candidate files → returns `[]`.
      - 5 candidate files (under the 7-daily cap) → all 5 kept; no pruning.
      - 14 consecutive daily files (Sun..Sat..Sun..Sat) → 7 latest dailies + the 4 Sundays among the older 7 (or fewer if not 4 Sundays present in the 14).
      - 2 same-day timestamps (e.g. `diederik-2026-05-10-030000.sqlite` and `diederik-2026-05-10-153000.sqlite`) → both count as separate dailies (the "7 daily" rule is about the 7 most-recent FILES, not 7 distinct days).
      - A `.suspect` file mixed in (`diederik-2026-05-09-030000.sqlite.suspect`) → passed through (kept).
      - A `pre-restore-2026-05-11-120000.sqlite` file → passed through (kept) — the regex anchors on the `diederik-` prefix.
