```
final readonly class Percentile {
    /** @param list<int> $sortedValues */
    public function p10(array $sortedValues): int;  // R-7 linear interpolation at p=10
    public function p50(array $sortedValues): int;
    public function p90(array $sortedValues): int;
}

final readonly class CadenceJitter {
    public function __construct(private \Modules\Core\Public\Contracts\Clock $clock) {}
    /** @param list<\Modules\Forecasting\Internal\Pipeline\ForecastContribution> $contributions */
    public function apply(array $contributions, int $jitterDays = 3): array;
        // Returns contributions with low/point/high spread widened by ±jitterDays days of
        // adjacent occurrence overlap. Per-contribution date stays; the band thickens.
}
```

The R-7 method (Wikipedia "Percentile §Linear interpolation between closest ranks", cited in RESEARCH Don't Hand-Roll):

```
For n samples, percentile p (0-100):
  index = (n - 1) × (p / 100)
  k = floor(index)
  d = index - k
  if k+1 < n: return sortedValues[k] + d × (sortedValues[k+1] - sortedValues[k])
  else: return sortedValues[k]
```

    ```
    /** @param list<int> $values  Unsorted list of observed amounts (in minor units; signed). */
    public function p10(array $values): int { return $this->percentile($values, 10); }
    public function p50(array $values): int { return $this->percentile($values, 50); }
    public function p90(array $values): int { return $this->percentile($values, 90); }

    private function percentile(array $values, int $p): int
    {
        if (count($values) === 0) {
            throw new \InvalidArgumentException('Cannot compute percentile of empty list.');
        }
        if (count($values) === 1) {
            return $values[0];
        }
        sort($values, SORT_NUMERIC);
        $n = count($values);
        $index = ($n - 1) * ($p / 100);
        $k = (int) floor($index);
        $d = $index - $k;
        if ($k + 1 < $n) {
            return (int) round($values[$k] + $d * ($values[$k + 1] - $values[$k]));
        }
        return $values[$k];
    }
    ```

    PHPDoc cites: "R-7 method: Wikipedia 'Percentile §Linear interpolation between closest ranks'. Chosen because nearest-rank fails on n=6 where each percentile maps to a single observation; R-7 interpolates continuously."

    `final readonly class CadenceJitter` constructor DI: `Clock $clock` (Wave 5 jitter is deterministic for now — no random; the jitter is "spread the contribution's band across the ±3 day window by spawning fractional contributions"; future plans may make it stochastic):

    ```
    /** @param list<ForecastContribution> $contributions */
    public function apply(array $contributions, int $jitterDays = 3): array
    {
        $jittered = [];
        $window = $jitterDays * 2 + 1;
        $weight = (int) round(100 / $window);   // distribute the contribution across the window
        foreach ($contributions as $c) {
            for ($offset = -$jitterDays; $offset <= $jitterDays; $offset++) {
                $jittered[] = new ForecastContribution(
                    date: $c->date->copy()->addDays($offset),
                    pointMinor: (int) round($c->pointMinor * $weight / 100),
                    lowMinor: (int) round($c->lowMinor * $weight / 100),
                    highMinor: (int) round($c->highMinor * $weight / 100),
                    currency: $c->currency,
                    fxRateUsed: $c->fxRateUsed,
                    seriesId: $c->seriesId,
                    accountId: $c->accountId,
                );
            }
        }
        return $jittered;
    }
    ```

    PHPDoc explains: "Spreads each contribution's amount across a ±jitterDays window using equal weighting. The daily fold's quadrature behavior naturally widens the band around uncertain charge dates because each day in the window receives a fractional contribution. Effectively converts a 'point on day D' into a 'broad spread across [D-3, D+3]'."
