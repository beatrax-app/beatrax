    2. **Implement `LoopbackOnly` middleware:**
       ```php
       namespace Modules\Core\Internal\Http\Middleware;

       use Closure;
       use Illuminate\Http\Request;
       use Symfony\Component\HttpFoundation\Response;

       final class LoopbackOnly
       {
           private const LOOPBACK_ADDRESSES = ['127.0.0.1', '::1'];

           public function handle(Request $request, Closure $next): Response
           {
               $serverAddr = $request->server('SERVER_ADDR');

               if ($serverAddr !== null && !in_array($serverAddr, self::LOOPBACK_ADDRESSES, true)) {
                   throw new \Symfony\Component\HttpKernel\Exception\NotFoundHttpException();
               }

               return $next($request);
           }
       }
       ```
       Note: `abort(404)` is a helper — banned. Throwing `NotFoundHttpException` directly is the DI-compliant equivalent.

           public function handle(Request $request, Closure $next): Response

## Trust Boundaries (Phase 1 scope — Plan 02 portion)

| Boundary | Description |
|----------|-------------|
| Browser → Laravel HTTP | The login form is the only HTTP entry that accepts unauthenticated input. CSRF + Fortify's rate limiter cover the classic abuse cases. Plus: `LoopbackOnly` enforces that the request originated from 127.0.0.1 / ::1. |
| Database connection → SQLite file | `SqliteOptimizationsProvider` applies pragmas on every connection. A SQLite file outside iCloud / OneDrive / Dropbox is required by the install command's PLT-02 check. |
| Install command → filesystem | InstallCommand creates the SQLite file; PLT-02 path check prevents accidental cloud-sync. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | S (Spoofing) | Login form — credential theft | mitigate | Fortify's `authenticateUsing` checks bcrypt hashes via `Illuminate\Contracts\Hashing\Hasher`; `'hashed'` cast on `User::password`; rate-limiter `login` applies to /login (Fortify default 5/min). |
