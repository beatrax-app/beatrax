    5. **`ImportPipeline`** (Internal — orchestrates the 3 stages):
       ```php
       namespace Modules\Import\Internal\Pipeline;

       use Modules\Core\Models\User;
       use Modules\Import\Internal\Pipeline\Stages\FingerprintStage;
       use Modules\Import\Internal\Pipeline\Stages\NormalizeStage;
       use Modules\Import\Internal\Pipeline\Stages\ParseStage;
       use Modules\Import\Public\Dto\PreviewRowDto;
       use Modules\Import\Public\Dto\UnknownIban;
       use Modules\Ingestion\Public\Contracts\AccountResolver;
       use Modules\Ingestion\Public\Dto\KnownAccount;
       use Modules\Ingestion\Public\Dto\UnknownAccount;

       final class ImportPipeline
       {
           public function __construct(
               private readonly ParseStage $parse,
               private readonly NormalizeStage $normalize,
               private readonly FingerprintStage $fingerprint,
           ) {}

           /**
            * @return array{rows: list<PreviewRowDto>, canonical: list<\Modules\Ledger\Public\Dto\CanonicalTransaction>, unknownIbans: list<UnknownIban>}
            */
           public function preview(string $localPath, string $sourceFormat, AccountResolver $accounts, User $user, int $importRunId): array
           {
               $parsed = $this->parse->run($localPath, $sourceFormat, $accounts);
               $preview = [];
               $canonical = [];
               $unknownIbans = [];

               foreach ($parsed as $source) {
                   $resolution = $accounts->resolve($source->ownIban);
                   if ($resolution instanceof UnknownAccount) {
                       $unknownIbans[$source->ownIban] = new UnknownIban(
                           iban: $source->ownIban,
                           seenCounterpartyName: $source->counterpartyName,
                       );
                       // Still produce a placeholder PreviewRowDto with status='error' until resolved:
                       $preview[] = new PreviewRowDto(
                           rowIndex: $source->sourceRowIndex,
                           status: 'error',
                           accountId: null,
                           bookedAt: $source->bookedAt->format('d-m-Y'),
                           counterpartyName: $source->counterpartyName,
                           categoryName: null,
                           amountMinor: $source->amountMinor,
                           currency: $source->currency,
                           error: "Unknown account for IBAN {$source->ownIban}. Name it to continue.",
                       );
                       continue;
                   }

                   /** @var KnownAccount $resolution */
                   try {
                       $normalized = $this->normalize->run($source, $resolution->accountId, $user, $importRunId);
                   } catch (\Throwable $e) {
                       $preview[] = new PreviewRowDto(
                           rowIndex: $source->sourceRowIndex,
                           status: 'error',
                           accountId: $resolution->accountId,
                           bookedAt: $source->bookedAt->format('d-m-Y'),
                           counterpartyName: $source->counterpartyName,
                           categoryName: null,
                           amountMinor: $source->amountMinor,
                           currency: $source->currency,
                           error: $e->getMessage(),
                       );
                       continue;
                   }

                   $isDuplicate = $this->fingerprint->isExistingFingerprint($normalized);
                   $preview[] = new PreviewRowDto(
                       rowIndex: $source->sourceRowIndex,
                       status: $isDuplicate ? 'duplicate' : 'new',
                       accountId: $resolution->accountId,
                       bookedAt: $source->bookedAt->format('d-m-Y'),
                       counterpartyName: $source->counterpartyName,
                       categoryName: null,
                       amountMinor: $source->amountMinor,
                       currency: $source->currency,
                       error: null,
                   );
                   if (!$isDuplicate) {
                       $canonical[] = $normalized;
                   }
               }

               return [
                   'rows' => $preview,
                   'canonical' => $canonical,
                   'unknownIbans' => array_values($unknownIbans),
               ];
           }
       }
       ```

    7. **`NormalizeStage`** — converts `SourceTransactionDto` → `CanonicalTransaction`; applies the Pitfall-5 sentinel + ASN sign-to-type mapping (A13):
       ```php
       namespace Modules\Import\Internal\Pipeline\Stages;

       use Modules\Core\Models\User;
       use Modules\Ingestion\Public\Dto\SourceTransactionDto;
       use Modules\Ledger\Public\Dto\CanonicalTransaction;
       use Modules\Ledger\Public\Services\FingerprintComposer;

       final class NormalizeStage
       {
           private const NO_COUNTERPARTY = '_no_counterparty';

           public function __construct(private readonly FingerprintComposer $fingerprints) {}

           public function run(SourceTransactionDto $source, int $accountId, User $user, int $importRunId): CanonicalTransaction
           {
               $name = $source->counterpartyName;
               if ($name === null || trim($name) === '') {
                   // Pitfall 5 mitigation: composite UNIQUE needs NOT NULL to catch duplicates
                   $normalized = self::NO_COUNTERPARTY;
               } else {
                   $normalized = $this->fingerprints->normalize($name);
                   if ($normalized === '') {
                       $normalized = self::NO_COUNTERPARTY;                  // diacritic-only or punctuation-only names
                   }
               }

               $type = match (true) {
                   $source->amountMinor > 0 => 'income',
                   $source->amountMinor < 0 => 'expense',
                   default                  => 'adjustment',
               };

               return new CanonicalTransaction(
                   userId: (int) $user->id,
                   accountId: $accountId,
                   type: $type,
                   postedAt: $source->postedAt,
                   bookedAt: $source->bookedAt,
                   valueDate: $source->valueDate,
                   amountMinor: $source->amountMinor,
                   currency: $source->currency,
                   settledAmountMinor: $source->amountMinor,             // ASN settles in EUR; native == settled (MC-01 schema lives even without UI)
                   settledCurrency: $source->currency,
                   fxRateUsed: null,
                   counterpartyName: $source->counterpartyName,
                   counterpartyIban: $source->counterpartyIban,
                   counterpartyNormalized: $normalized,
                   normalizationVersion: $this->fingerprints->version(),
                   description: $source->description,
                   categoryId: null,
                   sourceFormat: 'asn-csv',
                   importRunId: $importRunId,
                   sourceRowIndex: $source->sourceRowIndex,
                   sourceRef: $source->sourceRef,
               );
           }
       }
       ```

    9. **`PreviewCache`** (Internal — keyed on importRunId). **LOCKED implementation — JSON serialization only, no `unserialize` on user-derived data anywhere** (deserialization-of-untrusted-data is a known RCE class; even `unserialize($raw, ['allowed_classes' => ...])` still ROPs through DTO constructors and is forbidden here):
       ```php
       namespace Modules\Import\Internal\Pipeline;

       use Illuminate\Contracts\Cache\Repository;
       use Modules\Core\Public\Contracts\Clock;
       use Modules\Import\Public\Dto\ImportPreviewResult;
       use Modules\Ledger\Public\Dto\CanonicalTransaction;

       final class PreviewCache
       {
           public function __construct(
               private readonly Repository $cache,
               private readonly Clock $clock,
           ) {}

           /**
            * @param list<CanonicalTransaction> $canonical
            */
           public function put(int $importRunId, ImportPreviewResult $result, array $canonical): void
           {
               $ttl = $this->clock->now()->addMinutes(30);

               // Preview shape (small, owned by us) — store the spatie/laravel-data array form.
               $this->cache->put(
                   "import.{$importRunId}.preview",
                   $result->toArray(),
                   $ttl,
               );

               // Canonical rows — JSON, hydrated back via Data::from on read.
               $this->cache->put(
                   "import.{$importRunId}.canonical",
                   json_encode(
                       array_map(static fn (CanonicalTransaction $c): array => $c->toArray(), $canonical),
                       JSON_THROW_ON_ERROR,
                   ),
                   $ttl,
               );
           }

           /**
            * @return list<CanonicalTransaction>
            */
           public function getCanonical(int $importRunId): array
           {
               $raw = $this->cache->get("import.{$importRunId}.canonical");
               if ($raw === null) {
                   return [];
               }
               $list = json_decode($raw, associative: true, flags: JSON_THROW_ON_ERROR);
               return array_map(static fn (array $row): CanonicalTransaction => CanonicalTransaction::from($row), $list ?? []);
           }

           public function getPreview(int $importRunId): ?ImportPreviewResult
           {
               $raw = $this->cache->get("import.{$importRunId}.preview");
               return $raw === null ? null : ImportPreviewResult::from($raw);
           }

           public function forget(int $importRunId): void
           {
               $this->cache->forget("import.{$importRunId}.preview");
               $this->cache->forget("import.{$importRunId}.canonical");
           }
       }
       ```
       DI notes:
       - `Clock` is injected, NOT the `now()` helper (which is banned per CLAUDE.md DI-only policy).
       - `JSON_THROW_ON_ERROR` makes malformed cache contents (corruption / version skew) loud — `getCanonical` raises rather than silently dropping rows.
       - `CanonicalTransaction::from($row)` is the spatie/laravel-data hydration path; it validates types as it constructs the DTO. No constructor side-effects fire from arbitrary unserialized strings — the attack surface is bounded to the JSON shape the DTO accepts.
       - **Do NOT introduce `unserialize()` anywhere in this file or in any `Modules/Import/Internal/Pipeline/*` file** — even with `allowed_classes`. The locked test asserts the literal absence.

       final class RunImport implements RunsImports
       {
           public function __construct(
               private readonly ImportPipeline $pipeline,
               private readonly PreviewCache $cache,
               private readonly DatabaseManager $db,
               private readonly Clock $clock,
               private readonly ConfirmImport $confirmAction,
               private readonly FilesystemFactory $files,
           ) {}

           public function runFromUpload(string $localPath, string $sourceFormat, User $user, string $originalFilename): ImportPreviewResult
           {
               $sha = hash_file('sha256', $localPath);

               // File-layer idempotency shortcut: if this user already imported this exact SHA, return the existing preview result.
               $existing = ImportRun::query()->where('user_id', $user->id)->where('sha256', $sha)->first();
               if ($existing && $existing->status === 'confirmed') {
                   // Re-uploading a confirmed file: surface an "all duplicates" preview
                   return new ImportPreviewResult(importRunId: (int) $existing->id, rows: [], accountsToName: []);
               }

               $importRun = $existing ?? ImportRun::create([
                   'user_id' => $user->id,
                   'source_format' => $sourceFormat,
                   'raw_file_path' => $localPath,
                   'sha256' => $sha,
                   'uploaded_at' => $this->clock->now(),
                   'status' => 'previewed',
               ]);

               $accounts = new EloquentAccountResolver($user);
               $result = $this->pipeline->preview($localPath, $sourceFormat, $accounts, $user, (int) $importRun->id);

               $previewResult = new ImportPreviewResult(
                   importRunId: (int) $importRun->id,
                   rows: $result['rows'],
                   accountsToName: $result['unknownIbans'],
               );
               $this->cache->put((int) $importRun->id, $previewResult, $result['canonical']);

               return $previewResult;
           }

           public function runAndConfirm(string $localPath, string $sourceFormat, User $user, string $originalFilename = 'fixture.csv'): ImportConfirmResult
           {
               $preview = $this->runFromUpload($localPath, $sourceFormat, $user, $originalFilename);
               return ($this->confirmAction)($preview->importRunId, $user);
           }
       }

       use Illuminate\Database\DatabaseManager;
       use Modules\Core\Models\User;
       use Modules\Core\Public\Contracts\Clock;
       use Modules\Import\Internal\Pipeline\PreviewCache;

       final class ConfirmImport implements ConfirmsImports
       {
           public function __construct(
               private readonly RecordsTransactions $recorder,
               private readonly PreviewCache $cache,
               private readonly DatabaseManager $db,
               private readonly Clock $clock,
           ) {}

           public function __invoke(int $importRunId, User $user): ImportConfirmResult
           {
               $importRun = ImportRun::query()
                   ->where('id', $importRunId)
                   ->where('user_id', $user->id)
                   ->firstOrFail();

               if ($importRun->status === 'confirmed') {
                   return new ImportConfirmResult($importRunId, 0, 0, 0);
               }

               $canonical = $this->cache->getCanonical($importRunId);
               $preview = $this->cache->getPreview($importRunId);
               $errorCount = $preview ? count(array_filter($preview->rows, fn ($r) => $r->status === 'error')) : 0;

               $result = ($this->recorder)($canonical);

               $importRun->update([
                   'inserted_count' => $result->inserted,
                   'duplicate_count' => $result->duplicates,
                   'error_count' => $errorCount,
                   'confirmed_at' => $this->clock->now(),
                   'status' => 'confirmed',
               ]);

               $this->cache->forget($importRunId);

               return new ImportConfirmResult(
                   importRunId: $importRunId,
                   inserted: $result->inserted,
                   duplicates: $result->duplicates,
                   errors: $errorCount,
               );
           }
       }

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → upload endpoint | User uploads a file. CSRF + auth + Livewire's `WithFileUploads` validation are the gatekeepers. |
| Upload → disk | File saved to `storage/imports/{user_id}/{import_run_id}/{safe_filename}`. Filename sanitized to `[A-Za-z0-9_-]+\.csv`. |
| Cache → pipeline replay | PreviewCache holds canonical DTOs between preview and confirm. JSON serialization (not `unserialize`) keeps the boundary safe. |
| Adapter output → DB | `RecordTransactions` is the only writer; runs inside `DB::transaction(...)`. |

## STRIDE Threat Register (ASVS L1)

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | E (Elevation of Privilege) | Path traversal in uploaded filename | mitigate | `$safeName = preg_replace('/[^A-Za-z0-9_-]+/', '_', pathinfo($original, PATHINFO_FILENAME)) . '.csv'`. The user-supplied original name is NEVER used to construct disk paths. The directory `imports/{user_id}/{import_run_id}/` is generated server-side. |
| T-05-02 | D (Denial of Service) | Oversized CSV file | mitigate | Livewire validation: `max:10240` (10 MB). Adapter is `Generator` — bounded memory. |
| T-05-03 | T (Tampering) | Cross-user import access | mitigate | RunImport / ConfirmImport / DiscardImport ALL check `ImportRun::where('user_id', $user->id)`. `UserScope` on `import_runs` adds the same WHERE. `firstOrFail` 404s on cross-user attempts. |
| T-05-04 | I (Information Disclosure) | Preview cache survives logout / cross-session | mitigate | Cache key includes `importRunId`; the ConfirmImport action verifies the run belongs to the current user before reading the cache. If user A's importRunId is guessed by user B, ConfirmImport's `firstOrFail` blocks. (Phase 1 has one user — defense is for v2.) |
| T-05-05 | S (Spoofing) | Forged `confirm` request bypassing preview | mitigate | ConfirmImport requires `importRunId` + authenticated user; the importRun must exist with `user_id = current.user.id`; only `status='previewed'` runs are confirmable. |
| T-05-06 | T (Tampering) | Re-importing a confirmed file → re-inserting | mitigate | File-layer UNIQUE on `(user_id, sha256)` + RunImport's early-return when status='confirmed' returns an empty preview. Row-layer composite UNIQUE on transactions backs it up. Tested by `IdempotencyContractTest`. |
| T-05-07 | I (Information Disclosure) | Error message leaks server path / stack trace | mitigate | UI-SPEC §Error states defines the user-facing strings explicitly. Adapter exceptions are caught in `ImportPipeline::preview()` and converted to `PreviewRowDto::error` text — only the message bubbles, not the trace. Production-mode Laravel hides stack traces anyway. |
| T-05-08 | T (Tampering) | CSV-injection (Pitfall not mitigated in v1) | accept | Phase 1 does not export CSV; ingestion is the only direction. SUMMARY notes the v2 consideration. |
| T-05-09 | E (Elevation of Privilege) | Unsupported source format (`'eml-import'` future) processed via adapter resolver | mitigate | `SourceAdapterRegistry::for()` throws `UnsupportedFormatException` on unknown format strings. UploadWizard validation pins `sourceFormat` to `'in:asn-csv'`. |
| T-05-10 | T (Tampering) | Unauthorized account naming (creating accounts under a different user) | mitigate | `AccountNamer::__invoke($iban, $name, $user)` stamps `user_id = $user->id`. `UserScope` filters reads. |
| T-05-11 | E (Elevation of Privilege) | Deserialization-of-untrusted-data via `unserialize()` on cache contents | mitigate | `PreviewCache` LOCKED to `json_encode` + `CanonicalTransaction::from($row)` (spatie/laravel-data). `unserialize()` is banned in `Modules/Import/Internal/Pipeline/PreviewCache.php`; an acceptance-criterion grep gate enforces the absence. Rationale: PHP `unserialize` (even with `allowed_classes`) instantiates DTO constructors with attacker-controlled strings — out-of-scope for Phase 1's threat model, and easy to eliminate by using JSON for the only structured boundary that crosses the cache. |
