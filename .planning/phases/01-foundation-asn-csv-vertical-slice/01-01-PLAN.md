Forbidden (must NEVER appear in non-test, non-Routes, non-Migrations code):
  auth(), Auth::*           -> inject Core\Public\Contracts\CurrentUser (Plan 02 ships the contract)
  request(), Request::*     -> type-hint \Illuminate\Http\Request in method signature
  config(), Config::*       -> inject \Illuminate\Contracts\Config\Repository
  app(), App::*, resolve()  -> inject the concrete type / contract
  route(), URL::*, url()    -> inject \Illuminate\Contracts\Routing\UrlGenerator
  now(), today()            -> inject Core\Public\Contracts\Clock (Plan 02)
  cache(), Cache::*         -> inject \Illuminate\Contracts\Cache\Repository
  event(), Event::*         -> inject \Illuminate\Contracts\Events\Dispatcher
  session(), Session::*     -> inject \Illuminate\Contracts\Session\Session
  DB::*                     -> inject \Illuminate\Database\DatabaseManager
                              or \Illuminate\Database\ConnectionInterface
  Log::*                    -> inject \Psr\Log\LoggerInterface
  Storage::*                -> inject \Illuminate\Contracts\Filesystem\Factory

Exempt from the ban (documented in phpstan.neon excludePaths):
  - **/Routes/*.php                       (framework lifecycle — route registration)
  - **/Database/Migrations/*.php          (framework lifecycle — Schema:: facade)
  - **/tests/**                           (test code — `actingAs`, `withServerVariables`, etc. are first-class)
  - Modules/*/Database/Seeders/*.php      (framework lifecycle)

Allowed everywhere:
  - Eloquent instantiation: new Transaction()
  - Eloquent static finders: Transaction::find($id), Transaction::where(...)->get()
  - $model->newQuery()
  - Trait usage on models

Boundary rule (custom; Plan 01 ships it):
  - From Modules\X\**, you MAY import:
      Modules\X\**            (own internals OK)
      Modules\Y\Public\**     (cross-module Public surface OK)
      Modules\Y\Models\**     (Eloquent direct OK per CLAUDE.md)
      Illuminate\**, brick\**, league\**, spatie\**, etc.
  - From Modules\X\**, you MUST NOT import:
      Modules\Y\Internal\**   (FAIL)
      Modules\Y\Database\**   (FAIL — except inside Modules\Y itself)
      Modules\Y\Http\Livewire\**  (FAIL — Livewire components are internal UI)
      Modules\Y\Providers\**  (FAIL)
  where Y != X. Inside Modules\X\tests\, imports of Modules\X\Internal\** are allowed.
