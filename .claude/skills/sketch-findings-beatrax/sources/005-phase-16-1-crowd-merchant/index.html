About the shared list

Suggestions go into a public file in the diederik repo (merchant-mappings.yaml) as a draft pull request from your machine. You're not sharing any of your transaction amounts or dates — only the mystery code and the human name you propose. A maintainer reviews and merges; on the next diederik update, that mapping ships to everyone.

The shared list currently contains 1,247 mappings from 89 contributors, covering ASN, ING, Rabobank, ICS, PayPal, and Google Play.
